# Node.js SDK

The `@nexus-signal/node` library provides server-side bindings for triggering workflows, managing scheduled tasks, syncing tenants, and secure subscriber validation.

## Client Initialization

Initialize the `NexusClient` on your server. Avoid invoking this constructor inside serverless function scopes repeatedly; instead, export a single instance to leverage keep-alive connections.

```ts title="lib/nexus.ts"
import { NexusClient } from '@nexus-signal/node';

export const nexus = new NexusClient({
  secretKey: process.env.NEXUS_SECRET_KEY!, // e.g., sk_prd_...
  baseUrl: process.env.NEXUS_BASE_URL || 'https://api.nexussignal.dev',
  timeout: 5000,
});
```

## Triggering Workflows

Emits an event trigger to initiate your configured visual workflow paths:

```ts title="routes/order.ts"
import { nexus } from '../lib/nexus';

export async function handleOrderShipped(orderId: string, userId: string) {
  const result = await nexus.workflows.trigger({
    workflowName: 'order.shipped',
    recipients: [
      {
        externalId: userId,
        email: 'customer@acme.io',
        phoneNumber: '+15550198234',
        timezone: 'America/New_York',
        locale: 'en',
      },
    ],
    data: {
      orderNumber: orderId,
      shippingCarrier: 'FedEx',
      trackingLink: 'https://fedex.com/track/12345',
    },
  });

  if (!result.ok) {
    console.error('Trigger failed:', result.error);
    if (result.queued) {
      console.warn('Payload buffered in memory due to circuit opening.');
    }
  }
}
```

## Secure HMAC Generation

Generate a cryptographically secure signature to authenticate websocket notifications:

```ts
// Returns a 64-character SHA-256 hex signature
const signature = nexus.auth.generateHmacSignature('user_active_99');
```

Alternatively, you can compute this without initializing the client:

```ts
import { generateHmacSignature } from '@nexus-signal/node';

const signature = generateHmacSignature(process.env.NEXUS_SECRET_KEY!, 'user_active_99');
```

## B2B Tenants & Branding

Manage white-labeled email templates, in-app theme styles, and preference defaults for distinct corporate customers:

```ts
// Create or update a customer tenant branding override
const tenantResult = await nexus.tenants.upsert({
  externalId: 'tenant_acme_corp',
  name: 'Acme Corporation',
  branding: {
    logo: 'https://cdn.acme.io/logos/logo.png', // Strict Type Key: logo
    primaryColor: '#0070f3',
    footerHtml: '<p>Sent by Acme Corp, 123 Main St</p>',
  },
});

// Trigger a workflow scoped to this tenant branding context
await nexus.workflows.trigger({
  workflowName: 'invoice.finalized',
  tenant: 'tenant_acme_corp',
  recipients: [{ externalId: 'alex_acme' }],
  data: { amount: '$450.00' },
});
```

## Shared Entity Subscriptions (Objects)

Send messages to virtual entities (channels, document boards, projects) and let Nexus resolve watches automatically:

```ts
// Define the entity
await nexus.objects.set({
  collection: 'workspaces',
  externalId: 'ws_eng_team',
  name: 'Engineering Workspace',
});

// Add subscribers
await nexus.objects.addSubscriptions('workspaces', 'ws_eng_team', {
  recipients: ['usr_alice_dev', 'usr_bob_ops'],
});

// Notify all watchers of the engineering workspace
await nexus.workflows.trigger({
  workflowName: 'workspace.announcement',
  recipients: [{ collection: 'workspaces', id: 'ws_eng_team' }],
  data: { msg: 'Scheduled database maintanance tonight.' },
});
```

## Broadcast Campaigns

Schedule and send campaigns to pre-configured subscriber segments:

```ts
const broadcast = await nexus.broadcasts.create({
  name: 'Platform Feature Update',
  workflowId: 'wf-uuid-goes-here',
  audienceId: 'aud-uuid-goes-here',
  data: { highlight: 'Dynamic Step Conditions are live!' },
});

if (broadcast.ok && broadcast.data?.broadcast?.id) {
  // Dispatch immediate broadcast execution
  await nexus.broadcasts.send(broadcast.data.broadcast.id);
}
```

## Recurring Schedules

Configure recurring workflow dispatches programmatically:

```ts
// Create recurring Monday schedule
await nexus.schedules.create({
  name: 'Weekly Usage Summary',
  workflowId: 'wf-uuid-goes-here',
  cronExpression: '0 9 * * 1', // Every Monday at 9:00 AM
  timezone: 'America/Los_Angeles',
  recipients: [{ externalId: 'user_analytics' }],
  data: { reportScope: 'seven_days' },
});

// Fetch active schedules
const list = await nexus.schedules.list({ page: 1, limit: 10 });

// Deactivate or purge schedules
await nexus.schedules.update('schedule-uuid', { active: false });
await nexus.schedules.delete('schedule-uuid');
```

## Code-First Workflow Syncing

You can sync your local TypeScript workflow definitions with the Nexus platform:

```ts
import { defineWorkflow } from '@nexus-signal/node';

const welcomeFlow = defineWorkflow('user.registration')
  .addChannel('IN_APP')
  .addDelay({ minutes: 15 })
  .addChannel('EMAIL')
  .toDefinition();

const result = await nexus.workflows.sync(welcomeFlow);
```

## Client Resilience & Failover

The Node SDK includes a **circuit breaker** and a local **memory buffer** to handle platform outages:

- **Circuit Breaker**: Trips to `OPEN` state after **5 consecutive failures** or request timeouts. During this period, outgoing triggers are blocked from calling the network and are queued locally. The circuit tries to recover automatically after **60 seconds**.
- **Memory Buffer**: Retains up to **500 trigger actions** in local memory.
- **Manual Flush**: If the client recovers, trigger these retries back to the platform using `flushRetries()`.

```ts
const resilientClient = new NexusClient({
  secretKey: process.env.NEXUS_SECRET_KEY!,
  events: {
    onCircuitOpen: () => {
      console.warn('Nexus Circuit breaker opened.');
    },
    onCircuitClose: async () => {
      console.info('Nexus Circuit closed. Flushing buffers...');
      await resilientClient.workflows.flushRetries();
    },
    onBufferOverflow: (failedPayload) => {
      console.error('Local memory buffer full! Dropped payload:', failedPayload.workflowName);
    },
  },
});
```
