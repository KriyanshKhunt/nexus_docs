# Headless JS SDK

The `@nexus-signal/js` library is a framework-agnostic client wrapper for in-app notifications, preferences, and guides. It uses raw browser environments, making it ideal for **Vue 3**, **Svelte**, **SolidJS**, or **Vanilla JS** applications with zero bundled UI styling constraints.

---

## Initialization Options

Create a new client instance on client load:

```ts
import { NexusClient } from '@nexus-signal/js';

const nexus = new NexusClient({
  publicKey: 'pk_prd_your_public_key', // pk_dev_... or pk_prd_...
  subscriberId: 'user_active_99',
  hmacSignature: 'computed_hmac_hex_signature',
  apiBaseUrl: 'https://api.nexussignal.dev',
});

// Start WebSocket transport and fetch initial states
await nexus.connect();
```

## Emitter Events

Register listener callbacks for real-time state changes. The `.on()` method returns an un-subscription cleanup function.

```ts
// Listen to new messages
const unsubscribe = nexus.on('notification.received', (notification) => {
  console.log('New notification received:', notification.title);
  alert(`Alert: ${notification.body}`);
});

// Unbind listeners when destroying the component
unsubscribe();
```

## Sub-Client Instances

The `NexusClient` hosts dedicated namespaces to manage underlying structures:

### 1. Inboxes (`nexus.notifications`)

Manages lists, read states, and tag filters:

```ts
// Fetch active notifications
const list = nexus.notifications.items; // Array of current notifications
const count = nexus.notifications.unread; // Unread count

// Update states
await nexus.notifications.markRead('log-uuid-here');
await nexus.notifications.markAllRead();
await nexus.notifications.archive('log-uuid-here');

// Filter feed by tags
await nexus.notifications.refetch({ tags: ['billing'] });
```

### 2. Guides (`nexus.guides`)

Fetch and dismiss dashboard banners or modals:

```ts
// Fetch path-scoped guides
await nexus.guides.fetch({ pathname: window.location.pathname });

const activeGuides = nexus.guides.guides;

// Trigger view and action events
await nexus.guides.markSeen('guide-uuid-here');
await nexus.guides.markInteracted('guide-uuid-here');
await nexus.guides.dismiss('guide-uuid-here');
```

### 3. Preferences (`nexus.preferences`)

Fetch and update channel choices:

```ts
// Load preferences
await nexus.preferences.fetch();

const topics = nexus.preferences.topics;
const settings = nexus.preferences.preferences; // e.g. { topic_id: { EMAIL: true } }

// Update a preference value
await nexus.preferences.updatePreference('billing_topic_id', 'EMAIL', false);
```

## Framework Integration Examples

### 1. Vue 3 (Composition API)

```vue title="components/NotificationFeed.vue"
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue';
import { NexusClient } from '@nexus-signal/js';

const props = defineProps<{ hmac: string; userId: string }>();

const nexus = new NexusClient({
  publicKey: 'pk_dev_your_public_key',
  subscriberId: props.userId,
  hmacSignature: props.hmac,
});

const unreadCount = ref(0);
const messages = ref<any[]>([]);
let countUnsub: () => void;

onMounted(async () => {
  await nexus.connect();
  unreadCount.value = nexus.notifications.unread;
  messages.value = nexus.notifications.items;

  // Bind reactive updates
  countUnsub = nexus.on('notifications.count_changed', (count) => {
    unreadCount.value = count;
    messages.value = [...nexus.notifications.items];
  });
});

onUnmounted(() => {
  if (countUnsub) countUnsub();
  nexus.disconnect();
});
</script>

<template>
  <div class="inbox">
    <span>Unread notifications: {{ unreadCount }}</span>
    <div v-for="msg in messages" :key="msg.logId" class="item">
      <h6>{{ msg.title }}</h6>
      <button @click="nexus.notifications.markRead(msg.logId)">Mark Read</button>
    </div>
  </div>
</template>
```
