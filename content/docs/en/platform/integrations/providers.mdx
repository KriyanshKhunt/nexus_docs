---
title: Provider Credentials Catalog
description: Complete list of supported BYOP (Bring Your Own Provider) channels, provider IDs, and required credentials.
---

Nexus Signal runs on your own carrier connections. Connect any of the supported providers below in **Settings → Integrations** on the dashboard. All keys are encrypted at rest using AES-256-GCM.

---

## Email integration layer

| Provider ID | Provider label | Required credentials                                | Telemetry webhooks |
| :---------- | :------------- | :-------------------------------------------------- | :----------------- |
| `sendgrid`  | SendGrid       | `apiKey` (Secret)                                   | ✅ Supported       |
| `resend`    | Resend         | `apiKey` (Secret)                                   | ✅ Supported       |
| `ses`       | Amazon SES     | `accessKeyId`, `secretAccessKey` (Secret), `region` | —                  |
| `postmark`  | Postmark       | `serverToken` (Secret)                              | ✅ Supported       |
| `mailgun`   | Mailgun        | `apiKey` (Secret), `domain`                         | —                  |
