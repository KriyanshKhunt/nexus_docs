All routes require header: `x-nexus-public-key: pk_prd_…` and subscriber identification via query or body.

## Notifications (inbox)

### List notifications

```http
GET /v1/sdk/notifications?subscriberExternalId=user_42&page=1&limit=50&filter=unread
```

| Query                 | Values                                    |
| --------------------- | ----------------------------------------- |
| `filter`              | `unread`, `read`, `archived`              |
| `tag` / `tags`        | Comma-separated workflow topic tags       |
| `tenantId`            | Filter by tenant's internal database UUID |
| `dateFrom` / `dateTo` | ISO timestamps                            |

```json
{
  "notifications": [
    {
      "logId": "uuid",
      "title": "Order shipped",
      "body": "Track your package",
      "read": false,
      "archived": false,
      "at": "2026-07-02T14:00:00.000Z",
      "workflowName": "order.shipped",
      "actor": { "name": "Sarah Chen", "avatar": "https://..." },
      "actions": [{ "label": "View order", "url": "/orders/9912", "variant": "primary" }],
      "tags": ["orders"]
    }
  ],
  "total": 128,
  "page": 1,
  "limit": 50,
  "hasMore": true
}
```

### Mark read / unread

```http
POST /v1/sdk/notifications/:logId/read
POST /v1/sdk/notifications/:logId/unread
POST /v1/sdk/notifications/mark-all-read
Body: { "subscriberExternalId": "user_42" }
```

### Archive / delete

```http
POST /v1/sdk/notifications/:logId/archive
POST /v1/sdk/notifications/:logId/unarchive
DELETE /v1/sdk/notifications/:logId
```

### Unread count

```http
GET /v1/sdk/notifications/count?subscriberExternalId=user_42&filter=unread
```

## Guides (in-product)

### Fetch eligible guides

```http
GET /v1/sdk/guides?subscriberExternalId=user_42&pathname=/dashboard
```

Returns active banners, modals, tooltips matching user + page context.

### Record guide events

```http
POST /v1/sdk/guides/:guideId/events
```

```json
{ "subscriberExternalId": "user_42", "event": "seen" }
```

Events: `seen`, `interacted`, `archived`

## Preferences

```http
GET /v1/sdk/subscribers/:externalId/preferences
PUT /v1/sdk/subscribers/:externalId/preferences
```

```json
{
  "preferences": {
    "order.shipped": { "EMAIL": true, "SMS": false },
    "topic:marketing": { "EMAIL": false }
  }
}
```

## Events & topics

```http
GET /v1/sdk/notification-events?subscriberExternalId=user_42
GET /v1/sdk/topics
```
