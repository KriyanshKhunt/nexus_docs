---
title: Client SDK Backend API
description: Public-key authenticated browser/mobile API endpoints for real-time notification feeds, guide dispatches, and preferences.
---

The SDK API powers our client-side modules ([@nexus-signal/react](/docs/sdk/frontend/react), [@nexus-signal/js](/docs/sdk/frontend/js)). To protect credentials, these routes require public-key authentication (`pk_*`) and subscriber verification signatures.

---

## Authentication & headers

All client-facing requests must include:

- `x-nexus-public-key` header with a valid environment public key (`pk_dev_*`, `pk_stg_*`, or `pk_prd_*`).
- `subscriberExternalId` in the query string or request body to scope the session.

For real-time WebSocket connections or secure in-app bells, you should also pass the backend-generated `hmacSignature` to prevent user impersonation (see [Authentication & Security](/docs/platform/getting-started/authentication)).

## Endpoint summary

| Method   | Path                                          | Description                                                   |
| :------- | :-------------------------------------------- | :------------------------------------------------------------ |
| `GET`    | `/v1/sdk/notifications`                       | Fetch paginated in-app inbox notifications.                   |
| `GET`    | `/v1/sdk/notifications/count`                 | Retrieve unread/total message counts.                         |
| `POST`   | `/v1/sdk/notifications/:logId/read`           | Mark a notification as read.                                  |
| `POST`   | `/v1/sdk/notifications/:logId/unread`         | Mark a notification as unread.                                |
| `POST`   | `/v1/sdk/notifications/:logId/archive`        | Archive a notification from the active inbox feed.            |
| `POST`   | `/v1/sdk/notifications/:logId/unarchive`      | Restore an archived notification.                             |
| `POST`   | `/v1/sdk/notifications/mark-all-read`         | Mark all inbox messages read.                                 |
| `DELETE` | `/v1/sdk/notifications/:logId`                | Delete (soft delete) a notification.                          |
| `GET`    | `/v1/sdk/guides`                              | Retrieve eligible in-app guides matching page route.          |
| `POST`   | `/v1/sdk/guides/:guideId/events`              | Log guideSeen, guideInteracted, or guideArchived telemetry.   |
| `GET`    | `/v1/sdk/subscribers/:externalId/preferences` | Retrieve subscriber preference channels matrix.               |
| `PUT`    | `/v1/sdk/subscribers/:externalId/preferences` | Update subscriber preferences.                                |
| `GET`    | `/v1/sdk/notification-events`                 | Fetch active workflow event schemas for preferences grouping. |
| `GET`    | `/v1/sdk/topics`                              | Fetch active preference topics.                               |

## List notifications

Fetch the in-app inbox feed for the subscriber.

```http
GET /v1/sdk/notifications?subscriberExternalId=user_42&filter=unread&page=1&limit=25
x-nexus-public-key: pk_prd_your_public_key
```

### Query filters

- `subscriberExternalId`: string (Required).
- `filter`: string (Optional). Filter feed state: `unread`, `read`, or `archived`.
- `tag` / `tags`: string (Optional). Comma-separated list of workflow tags (e.g. `billing,invoices`).
- `tenantId`: string (Optional). Filter by B2B tenant database UUID.
- `dateFrom` / `dateTo`: string (Optional). ISO 8601 timestamps.

**Response body:**

      },

        {

## Update preferences

Retrieve or update a subscriber's opt-in/opt-out selections.

```http
PUT /v1/sdk/subscribers/user_42/preferences
x-nexus-public-key: pk_prd_your_public_key
Content-Type: application/json

{
  "preferences": {
    "billing.invoice": { "EMAIL": true, "SMS": false },
    "topic:marketing": { "EMAIL": false }
  }
}
```

_Note: Custom preference overrides are saved inside the subscriber's database row and bypass default configurations on future triggers._
