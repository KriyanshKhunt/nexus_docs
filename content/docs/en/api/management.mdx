---
title: Management API
description: Server-side and devtool endpoints to manage workflows, schedules, environments, and templates programmatically.
---

The **Management API** powers CLI sync commands, CI/CD integrations, and MCP service connections. All routes require secret key credentials.

---

## Authentication & access

- **Base path**: `/v1/management`
- **Auth**: Pass your environment-specific secret key as a Bearer token:
  `Authorization: Bearer sk_prd_your_secret_key`

---

## Workspace resources

### 1. Workflows

- `GET /v1/management/workflows`: List all workflow keys and nodes configured in the environment.
- `GET /v1/management/workflows/:name`: Get details of a workflow by its machine name.

### 2. Subscribers

- `GET /v1/management/subscribers`: List subscribers profiles (paginated, searchable).
- `GET /v1/management/subscribers/:id`: Get a subscriber's details by database UUID.
- `POST /v1/management/subscribers`: Register or identify a subscriber.
- `DELETE /v1/management/subscribers/:id`: Purge a subscriber (GDPR compliance).

### 3. B2B Tenants

- `GET /v1/management/tenants`: List B2B tenants.
- `PUT /v1/management/tenants`: Upsert (create or update) tenant branding configs.

### 4. Audience Segments

- `GET /v1/management/audiences`: List audience definitions.
- `POST /v1/management/audiences`: Create segment filters.

### 5. Broadcasts

- `GET /v1/management/broadcasts`: List all campaigns.
- `POST /v1/management/broadcasts`: Create a draft or scheduled broadcast.
- `POST /v1/management/broadcasts/:id/send`: Trigger immediate dispatch of a broadcast.

### 6. In-Product Guides

- `GET /v1/management/guides`: List active guide campaigns.
- `GET /v1/management/guides/:id`: Fetch guide details.
- `POST /v1/management/guides`: Register a guide campaign.
- `PUT /v1/management/guides/:id`: Update guide content or targeting.

### 7. Entity Objects

- `GET /v1/management/objects`: List watched objects.
- `PUT /v1/management/objects/:collection/:externalId`: Upsert a database watch target.
- `GET /v1/management/objects/:collection/:externalId`: Fetch an object watch target.
- `POST /v1/management/objects/:collection/:externalId/subscriptions`: Subscribe watchers.
- `DELETE /v1/management/objects/:collection/:externalId/subscriptions`: Unsubscribe watchers.

### 8. Email Templates & Layouts

- `GET /v1/management/email/layouts`: List custom HTML layouts.
- `POST /v1/management/email/layouts`: Upload a new HTML container layout.

### 9. Translations

- `GET /v1/management/translations`: List uploaded language bundles.
- `PUT /v1/management/translations`: Upload locale JSON translations mapping.

### 10. Schedules

- `GET /v1/management/schedules`: List all active scheduled tasks.

## Delivery logs tracing

Retrieve detailed delivery outcomes and logs for auditing purposes:

```http
GET /v1/management/logs/2db4c803-10ac-4bfa-8bf2-0cfb4db1b392
Authorization: Bearer sk_prd_your_secret_key
```
