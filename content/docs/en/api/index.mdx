# Nexus Signal API

**Base URL:** `https://api.nexussignal.dev/v1`

Programmatic access to triggers, product messaging, in-app inbox, and analytics. Ingestion endpoints return **202 Accepted** — delivery is asynchronous.

## Authentication modes

| Audience | Auth | Endpoints |
|----------|------|-----------|
| Server apps | `Authorization: Bearer sk_*` | `/workflows/trigger`, `/workflows/sync`, `/schedules/sdk` |
| Browser SDK | `x-nexus-public-key: pk_*` | `/sdk/*` |
| Dashboard | JWT session / Bearer | `/workflows/dashboard`, `/broadcasts`, `/audiences`, etc. |
| CLI / MCP | `Authorization: Bearer sk_*` | `/management/*` |

## Response conventions

- Triggers return **202 Accepted** (async processing)
- Errors return `{ error: string, code?: string, details?: object }`
- Rate limits apply per plan tier
