<DashboardAuth />

Dashboard base path: `/v1/tenants`

Management API (CLI/MCP): `GET|PUT /v1/management/tenants`

## List tenants

```http
GET /v1/tenants
Authorization: Bearer <jwt>
```

## Upsert tenant

```http
PUT /v1/tenants
Authorization: Bearer <jwt>
```

```json
{
  "externalId": "tenant_acme",
  "name": "Acme Corp",
  "branding": {
    "logoUrl": "https://cdn.acme.io/logo.png",
    "primaryColor": "#2563eb",
    "footerHtml": "<p>© Acme</p>"
  },
  "providerOverrides": {},
  "preferenceDefaults": {}
}
```

## Get / update / delete

```http
GET    /v1/tenants/:id
PATCH  /v1/tenants/:id
DELETE /v1/tenants/:id
```

## Trigger with tenant

```json
{
  "workflowName": "invoice.sent",
  "tenant": "tenant_acme",
  "recipients": [{ "externalId": "user_42" }],
  "data": {}
}
```

See [Per-tenant branding](/docs/platform/features/tenants).
