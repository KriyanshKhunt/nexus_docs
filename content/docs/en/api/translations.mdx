Base path: `/v1/management/translations`

## List translations

Fetch all uploaded localization dictionary bundles.

```http
GET /v1/management/translations
Authorization: Bearer sk_prd_…
```

Returns locale, namespace, and key count per file:

```json
{
  "translations": [
    {
      "id": "trans_123",
      "locale": "es",
      "namespace": "default",
      "keyCount": 3,
      "createdAt": "2026-07-26T12:00:00Z"
    }
  ]
}
```

---

## Upsert translation bundle

Upload a JSON dictionary containing localized strings for a BCP 47 locale.

```http
PUT /v1/management/translations
Authorization: Bearer sk_prd_…
```

```json
{
  "locale": "es",
  "namespace": "default",
  "content": {
    "welcome_message": "Bienvenido",
    "order_shipped": "Tu pedido ha sido enviado",
    "cta_view_order": "Ver pedido"
  }
}
```

Namespace defaults to `default`.
