---
title: Email Layouts API
description: Server-side and dashboard endpoints to manage HTML framing layouts and Handlebars partials.
---

Email layouts define the header, footer, and outer container frames for your HTML emails, while partials let you reuse snippets (e.g. CTA buttons, standard legal texts) inside template bodies.

---

## Access & paths

- **Server / SDK Management (`sk_*` auth)**: `GET` / `POST` under `/v1/management/email/layouts`
- **Dashboard Frontend (JWT auth)**: All routes under `/v1/email`

---

## Create layout

Create a new framing layout. The HTML layout must contain the placeholder `{{{content}}}` to compile the inner message templates.

```http
POST /v1/email/layouts
Authorization: Bearer <jwt_dashboard_token>
Content-Type: application/json

{
  "name": "corporate-newsletter",
  "htmlBody": "<html><head><style>body { font-family: sans-serif; }</style></head><body><header><img src=\"{{ logo }}\" /></header><main>{{{content}}}</main><footer>{{{footerHtml}}}</footer></body></html>",
  "variables": {
    "defaultFooter": "<p>© 2026 Acme Corp</p>"
  },
  "isDefault": true
}
```

### Request body fields

- `name`: string (Required). Lowercase alphanumeric key with dashes/underscores (`/^[a-z][a-z0-9_-]*$/`, max 64 chars).
- `htmlBody`: string (Required). Raw HTML code containing `{{{content}}}` (max 100 KB).
- `variables`: object (Optional). Custom key-value pairs representing layout default strings.
- `isDefault`: boolean (Optional). Set as the default layout for new email templates.

## Create partial

Register a reusable sub-template snippet.

```http
POST /v1/email/partials
Authorization: Bearer <jwt_dashboard_token>
Content-Type: application/json

{
  "name": "action-button",
  "description": "Standard green CTA button with tracking URL",
  "htmlBody": "<table border=\"0\" cellpadding=\"0\" cellspacing=\"0\"><tr><td align=\"center\" bgcolor=\"#10b981\" style=\"border-radius: 4px;\"><a href=\"{{url}}\" target=\"_blank\" style=\"font-size: 14px; font-family: sans-serif; color: #ffffff; text-decoration: none; padding: 12px 24px; border: 1px solid #10b981; display: inline-block; font-weight: bold;\">{{label}}</a></td></tr></table>"
}
```

- `name`: string (Required). Lowercase alphanumeric key with dashes/underscores (`/^[a-z][a-z0-9_-]*$/`, max 64 chars).
- `description`: string (Optional). Internal description of the partial (max 256 chars).
- `htmlBody`: string (Required). Raw HTML code (max 100 KB).

### Usage in templates

Include registered partials inside email templates using the standard Handlebars syntax:

```html
<p>Click the link below to verify your email address:</p>
{{> action-button url=data.verificationLink label="Verify Email" }}
```

## Limits

| Limit                             | Value         |
| :-------------------------------- | :------------ |
| Max layouts per environment       | 20            |
| Max partials per environment      | 100           |
| Max layout/partial HTML body size | 100 KB        |
| Name maximum length               | 64 characters |
