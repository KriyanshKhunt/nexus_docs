# API de Análises

A API de Análises recupera métricas agregadas, volumes de logs, durações de latência, mapas de calor de erros e custos de provedores para seus ambientes.

---

## Autenticação e Acesso

- **Caminho base**: `/v1/analytics`
- **Auth**: Requer um token de sessão JWT do usuário.
- **Parâmetros de consulta (query parameters)**:
  - `environment`: `DEVELOPMENT`, `STAGING` ou `PRODUCTION` (o padrão é `DEVELOPMENT`).
  - `timeframe`: por exemplo, `24h`, `7d`, `30d` (suportado por endpoints de série temporal).

---

## Resumo dos Endpoints

| Método | Caminho                           | Descrição                                                                                           |
| :----- | :-------------------------------- | :-------------------------------------------------------------------------------------------------- |
| `GET`  | `/v1/analytics/overview`          | Estatísticas principais do painel (contagens de ingestão, taxas de sucesso de entrega, conversões). |
| `GET`  | `/v1/analytics/overview/traffic`  | Contagens de séries temporais cronológicas agrupadas por canal.                                     |
| `GET`  | `/v1/analytics/overview/latency`  | Velocidades de processamento de ponta a ponta (da ingestão ao recebimento pelo provedor).           |
| `GET`  | `/v1/analytics/overview/pipeline` | Estatísticas de sucesso de roteamento de estados do pipeline.                                       |
| `GET`  | `/v1/analytics/overview/heatmap`  | Grade de erros de entrega agrupados por provedor de integração.                                     |
| `GET`  | `/v1/analytics/overview/cost`     | Análise de gastos agrupada por camada de provedor e workflows.                                      |

---

## Métricas de Visão Geral (Overview)

Obtém cartões de resumo de alto nível.

```http
GET /v1/analytics/overview?environment=PRODUCTION
Authorization: Bearer <jwt_dashboard_token>
```

**Corpo da resposta:**

```json
{
  "ingestedTriggers": 12542,
  "deliverySuccessRate": 99.42,
  "meanLatencyMs": 348.5,
  "conversionRoi": 8.45,
  "environment": "PRODUCTION"
}
```

---

## Séries Temporais de Tráfego

Busca volumes de disparos de hora em hora.

```http
GET /v1/analytics/overview/traffic?environment=PRODUCTION&timeframe=24h
Authorization: Bearer <jwt_dashboard_token>
```

**Corpo da resposta:**

```json
{
  "traffic": [
    { "timestamp": "2026-07-28T12:00:00Z", "email": 120, "sms": 45, "push": 320, "total": 485 },
    { "timestamp": "2026-07-28T13:00:00Z", "email": 140, "sms": 38, "push": 310, "total": 488 }
  ]
}
```

---

## Mapa de Calor de Erros

Recupera taxas de erro por provedor:

```http
GET /v1/analytics/overview/heatmap?environment=PRODUCTION
Authorization: Bearer <jwt_dashboard_token>
```

**Corpo da resposta:**

```json
{
  "heatmap": [
    { "providerId": "twilio", "errorCount": 12, "lastErrorAt": "2026-07-28T20:45:00Z" },
    { "providerId": "sendgrid", "errorCount": 2, "lastErrorAt": "2026-07-28T19:30:00Z" }
  ]
}
```

---

## Análise de Gastos (Visão Geral de Custos)

Analisa o uso do orçamento e os custos dos canais com base nos pesos configurados para os provedores:

```http
GET /v1/analytics/overview/cost?environment=PRODUCTION
Authorization: Bearer <jwt_dashboard_token>
```

**Corpo da resposta:**

```json
{
  "totalCostUsd": 423.18,
  "budgetUsd": 500.0,
  "budgetUsedPercent": 84.6,
  "budgetExceeded": false,
  "byChannel": [
    { "channel": "EMAIL", "costUsd": 12.18, "count": 12180 },
    { "channel": "SMS", "costUsd": 411.0, "count": 27400 }
  ],
  "byProvider": [
    { "providerId": "twilio", "label": "Twilio", "count": 27400, "costUsd": 411.0 },
    { "providerId": "sendgrid", "label": "SendGrid", "count": 12180, "costUsd": 12.18 }
  ],
  "byWorkflow": [
    { "workflowName": "auth.otp", "costUsd": 411.0 },
    { "workflowName": "billing.invoice", "costUsd": 12.18 }
  ]
}
```
