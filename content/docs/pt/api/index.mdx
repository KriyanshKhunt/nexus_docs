# API do Nexus Signal

**Base URL:** `https://api.nexussignal.dev/v1`

Acesso programático a triggers, mensagens de produto, inbox in-app e análises. Os endpoints de ingestão retornam **202 Accepted** — a entrega é assíncrona.

## Modos de Autenticação

| Audiência           | Auth                         | Endpoints                                                 |
| :------------------ | :--------------------------- | :-------------------------------------------------------- |
| Aplicações servidor | `Authorization: Bearer sk_*` | `/workflows/trigger`, `/workflows/sync`, `/schedules/sdk` |
| SDK de navegador    | `x-nexus-public-key: pk_*`   | `/sdk/*`                                                  |
| Painel de controle  | JWT session / Bearer         | `/workflows/dashboard`, `/broadcasts`, `/audiences`, etc. |
| CLI / MCP           | `Authorization: Bearer sk_*` | `/management/*`                                           |

## Convenções de Resposta

- Os triggers retornam **202 Accepted** (processamento assíncrono)
- Os erros retornam `{ error: string, code?: string, details?: object }`
- Os limites de taxa (rate limits) se aplicam conforme o plano de assinatura
