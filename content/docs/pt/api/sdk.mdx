# API de Backend do Client SDK

A API do SDK alimenta nossos módulos do lado do cliente ([@nexus-signal/react](/docs/sdk/frontend/react), [@nexus-signal/js](/docs/sdk/frontend/js)). Para proteger as credenciais, essas rotas exigem autenticação de chave pública (`pk_*`) e assinaturas de verificação do inscrito.

---

## Autenticação e Cabeçalhos

Todas as requisições voltadas para o cliente devem incluir:

- Cabeçalho `x-nexus-public-key` contendo uma chave pública de ambiente válida (`pk_dev_*`, `pk_stg_*` ou `pk_prd_*`).
- Parâmetro `subscriberExternalId` na string de consulta (query string) ou no corpo da requisição para delimitar o escopo da sessão.

Para conexões WebSocket em tempo real ou sinos in-app seguros, você também deve passar a assinatura `hmacSignature` gerada no backend para evitar falsificação de identidade de usuários (consulte [Autenticação e Segurança](/docs/platform/getting-started/authentication)).

---

## Resumo dos Endpoints

| Método   | Caminho                                       | Descrição                                                                       |
| :------- | :-------------------------------------------- | :------------------------------------------------------------------------------ |
| `GET`    | `/v1/sdk/notifications`                       | Busca notificações paginadas do inbox in-app.                                   |
| `GET`    | `/v1/sdk/notifications/count`                 | Recupera contagens de mensagens não lidas/totais.                               |
| `POST`   | `/v1/sdk/notifications/:logId/read`           | Marca uma notificação como lida.                                                |
| `POST`   | `/v1/sdk/notifications/:logId/unread`         | Marca uma notificação como não lida.                                            |
| `POST`   | `/v1/sdk/notifications/:logId/archive`        | Arquiva uma notificação do feed ativo do inbox.                                 |
| `POST`   | `/v1/sdk/notifications/:logId/unarchive`      | Restaura uma notificação arquivada.                                             |
| `POST`   | `/v1/sdk/notifications/mark-all-read`         | Marca todas as mensagens do inbox como lidas.                                   |
| `DELETE` | `/v1/sdk/notifications/:logId`                | Exclui (exclusão lógica) uma notificação.                                       |
| `GET`    | `/v1/sdk/guides`                              | Recupera guias in-app elegíveis que correspondem à rota da página.              |
| `POST`   | `/v1/sdk/guides/:guideId/events`              | Registra telemetria de guideSeen, guideInteracted ou guideArchived.             |
| `GET`    | `/v1/sdk/subscribers/:externalId/preferences` | Recupera a matriz de canais de preferência do inscrito.                         |
| `PUT`    | `/v1/sdk/subscribers/:externalId/preferences` | Atualiza as preferências do inscrito.                                           |
| `GET`    | `/v1/sdk/notification-events`                 | Busca esquemas de eventos de workflows ativos para agrupamento de preferências. |
| `GET`    | `/v1/sdk/topics`                              | Busca tópicos de preferência ativos.                                            |

## Listar Notificações

Busca o feed do inbox in-app para o inscrito.

```http
GET /v1/sdk/notifications?subscriberExternalId=user_42&filter=unread&page=1&limit=25
x-nexus-public-key: pk_prd_your_public_key
```

### Filtros de Consulta

- `subscriberExternalId`: string (Obrigatório).
- `filter`: string (Opcional). Filtra o estado do feed: `unread`, `read` ou `archived`.
- `tag` / `tags`: string (Opcional). Lista separada por vírgulas de tags do workflow (por exemplo, `billing,invoices`).
- `tenantId`: string (Opcional). Filtra pelo UUID do banco de dados do tenant B2B.
- `dateFrom` / `dateTo`: string (Opcional). Carimbos de data/hora ISO 8601.

**Corpo da resposta:**

```json
{
  "notifications": [
    {
      "logId": "2db4c803-10ac-4bfa-8bf2-0cfb4db1b392",
      "title": "Invoice Paid",

      "workflowName": "billing.invoice",
      "actor": {
        "name": "Acme Billing",
        "avatar": "https://cdn.acme.io/avatar.png"
      },
      "actions": [
        {
          "label": "Download PDF",
          "url": "/receipts/pdf/992",
          "style": "primary"
        }
      ],

    }

```

## Atualizar Preferências

Recupera ou atualiza as seleções de opt-in/opt-out de um inscrito.

```http
PUT /v1/sdk/subscribers/user_42/preferences
x-nexus-public-key: pk_prd_your_public_key
Content-Type: application/json

{
  "preferences": {
    "billing.invoice": { "EMAIL": true, "SMS": false },
    "topic:marketing": { "EMAIL": false }
  }
}
```

_Nota: As substituições de preferências personalizadas são salvas no banco de dados na linha do inscrito e ignoram as configurações padrão em disparos futuros._
