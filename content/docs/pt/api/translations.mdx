# API de Traduções

As Traduções são tabelas estáticas de strings de chave-valor mapeadas por localidade de idioma e namespace. Isso permite que os workflows interpolem strings localizadas dinamicamente em tempo de disparo.

---

## Acesso e Caminhos

- **Servidor para Servidor / SDK (autenticação com `sk_*`)**: O caminho raiz é `/v1/management/translations`
- **Frontend do Painel (autenticação com JWT)**: O caminho raiz é `/v1/translations`

---

## Resumo dos Endpoints

| Método   | Caminho de Gerenciamento (`sk_*`) | Caminho do Painel (JWT) | Descrição                                        |
| :------- | :-------------------------------- | :---------------------- | :----------------------------------------------- |
| `GET`    | `/v1/management/translations`     | `/v1/translations`      | Lista todos os pacotes de tradução no ambiente.  |
| `PUT`    | `/v1/management/translations`     | `/v1/translations`      | Cria ou atualiza (upsert) um pacote de tradução. |
| `GET`    | —                                 | `/v1/translations/:id`  | Recupera detalhes da tradução por UUID.          |
| `DELETE` | —                                 | `/v1/translations/:id`  | Exclui um pacote de tradução.                    |

---

## Criar/Atualizar Pacote de Tradução (Upsert)

Carrega ou atualiza uma tabela de tradução.

```http
PUT /v1/management/translations
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json
```

```json
{
  "locale": "es-MX",
  "namespace": "invoice-labels",
  "content": {
    "title.invoice_overdue": "Factura Vencida",
    "button.pay_now": "Pagar Ahora",
    "description.amount_due": "El monto total a pagar es {{amount}}."
  }
}
```

### Campos do Corpo da Requisição

- `locale`: string (Obrigatório). Código de idioma BCP 47 (máx. 35 caracteres, por exemplo, `es-MX`, `ja`, `pt-BR`).
- `namespace`: string (Opcional). Rótulo de categorização com distinção de maiúsculas/minúsculas (máx. 64 caracteres). Alfanumérico em letras minúsculas com hífen/sublinhado (`/^[a-z][a-z0-9_-]*$/`). O padrão é `default`.
- `content`: objeto (Obrigatório). Um dicionário plano de pares chave-valor de string (máx. 500 chaves).
  - **Chaves**: Devem começar com uma letra e conter caracteres alfanuméricos, pontos, sublinhados ou hifens (`/^[a-zA-Z][a-zA-Z0-9_.-]*$/`, máx. 128 caracteres).
  - **Valores**: Strings de modelos brutas (máx. 5.000 caracteres). Podem conter slots de variáveis do Handlebars.

## Listar Arquivos de Tradução

```http
GET /v1/management/translations
Authorization: Bearer sk_prd_your_secret_key
```

**Corpo da resposta:**

```json
{
  "translations": [
    {
      "id": "2db4c803-10ac-4bfa-8bf2-0cfb4db1b392",
      "locale": "es-MX",
      "namespace": "invoice-labels",
      "keyCount": 3,
      "createdAt": "2026-07-28T12:00:00.000Z",
      "updatedAt": "2026-07-28T21:00:00.000Z"
    }
  ]
}
```

## Limites

| Limite                                     | Valor            |
| :----------------------------------------- | :--------------- |
| Máximo de pacotes de tradução por ambiente | 50               |
| Máximo de chaves por arquivo de tradução   | 500              |
| Comprimento máximo da chave                | 128 caracteres   |
| Comprimento máximo do valor                | 5.000 caracteres |
| Comprimento máximo do namespace            | 64 caracteres    |
