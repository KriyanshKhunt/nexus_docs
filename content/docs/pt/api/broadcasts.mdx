<DashboardAuth />

Caminho base do painel (Dashboard): `/v1/broadcasts`

API de Gerenciamento: `GET|POST /v1/management/broadcasts`, `POST /v1/management/broadcasts/:id/send`

## Listar broadcasts

```http
GET /v1/broadcasts?status=COMPLETED&page=1
Authorization: Bearer <jwt>
```

## Criar broadcast

```http
POST /v1/broadcasts
Authorization: Bearer <jwt>
```

```json
{
  "name": "Q4 Update",
  "workflowId": "workflow-uuid",
  "audienceId": "audience-uuid",
  "scheduledAt": "2026-08-01T09:00:00Z"
}
```

Omita `scheduledAt` para rascunho; envie manualmente depois.

## Enviar imediatamente

```http
POST /v1/broadcasts/:id/send
```

## Cancelar

```http
POST /v1/broadcasts/:id/cancel
```

## Estados de um Broadcast

`DRAFT` · `SCHEDULED` · `SENDING` · `COMPLETED` · `FAILED` · `CANCELLED`

## Node SDK

```ts
await nexus.broadcasts.create({
  name: "Launch",
  workflowId: "workflow-uuid",
  audienceId: "audience-uuid",
});
await nexus.broadcasts.send(broadcastId);
```
