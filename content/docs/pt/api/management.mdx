# API de Gerenciamento

A **API de Gerenciamento** alimenta comandos de sincronização de CLI, integrações CI/CD e conexões do serviço MCP. Todas as rotas requerem credenciais de chave secreta.

---

## Autenticação e Acesso

- **Caminho base**: `/v1/management`
- **Autenticação**: Passe sua chave secreta específica do ambiente como um token Bearer:
  `Authorization: Bearer sk_prd_your_secret_key`

---

## Recursos do Workspace

### 1. Workflows

- `GET /v1/management/workflows`: Lista todas as chaves de workflows e nós configurados no ambiente.
- `GET /v1/management/workflows/:name`: Obtém detalhes de um workflow por seu nome de máquina.

### 2. Inscritos

- `GET /v1/management/subscribers`: Lista perfis de inscritos (paginado, pesquisável).
- `GET /v1/management/subscribers/:id`: Obtém detalhes de um inscrito pelo UUID do banco de dados.
- `POST /v1/management/subscribers`: Registra ou identifica um inscrito.
- `DELETE /v1/management/subscribers/:id`: Purga um inscrito (conformidade com a regulamentação de proteção de dados).

### 3. Tenants B2B

- `GET /v1/management/tenants`: Lista tenants B2B.
- `PUT /v1/management/tenants`: Salva/atualiza (upsert) as configurações de branding do tenant.

### 4. Segmentos de Audiências

- `GET /v1/management/audiences`: Lista definições de audiências.
- `POST /v1/management/audiences`: Cria filtros de segmentos.

### 5. Broadcasts

- `GET /v1/management/broadcasts`: Lista todas as campanhas.
- `POST /v1/management/broadcasts`: Cria um rascunho ou transmissão agendada.
- `POST /v1/management/broadcasts/:id/send`: Dispara o despacho imediato de uma transmissão.

### 6. Guias no Produto

- `GET /v1/management/guides`: Lista campanhas de guias ativas.
- `GET /v1/management/guides/:id`: Busca detalhes do guia.
- `POST /v1/management/guides`: Registra uma campanha de guia.
- `PUT /v1/management/guides/:id`: Atualiza o conteúdo ou direcionamento do guia.

### 7. Objetos de Entidades

- `GET /v1/management/objects`: Lista objetos observados.
- `PUT /v1/management/objects/:collection/:externalId`: Salva/atualiza (upsert) o destino de monitoramento de banco de dados.
- `GET /v1/management/objects/:collection/:externalId`: Obtém o destino de monitoramento de banco de dados.
- `POST /v1/management/objects/:collection/:externalId/subscriptions`: Inscreve observadores.
- `DELETE /v1/management/objects/:collection/:externalId/subscriptions`: Cancela a inscrição de observadores.

### 8. Modelos e Layouts de E-mail

- `GET /v1/management/email/layouts`: Lista layouts HTML personalizados.
- `POST /v1/management/email/layouts`: Carrega um novo layout de contêiner HTML.

### 9. Traduções

- `GET /v1/management/translations`: Lista pacotes de idiomas carregados.
- `PUT /v1/management/translations`: Carrega o mapeamento JSON de traduções locais.

### 10. Schedules (Agendamentos)

- `GET /v1/management/schedules`: Lista todas as tarefas agendadas ativas.

## Rastreamento de Logs de Entrega

Recupera logs e resultados detalhados de entrega para fins de auditoria:

```http
GET /v1/management/logs/2db4c803-10ac-4bfa-8bf2-0cfb4db1b392
Authorization: Bearer sk_prd_your_secret_key
```
