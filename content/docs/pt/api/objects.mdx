# API de Objetos e Assinaturas

Os Objetos representam entidades de negócios que produzem feeds em sua aplicação (por exemplo, `"projects"`, `"documents"`, `"repositories"`). O gerenciamento de assinaturas permite transmitir alertas para todos os inscritos que estão observando uma determinada entidade.

---

## Acesso e Caminhos

Esses endpoints suportam tanto sessões de JWT do painel quanto chaves secretas do servidor (`sk_*`):

- **Servidor para Servidor / SDK (autenticação com `sk_*`)**: O caminho raiz é `/v1/management/objects`
- **Frontend do Painel (autenticação com JWT)**: O caminho raiz é `/v1/objects`

---

## Resumo dos Endpoints

| Método   | Caminho de Gerenciamento (`sk_*`)                  | Caminho do Painel (JWT)                 | Descrição                                                  |
| :------- | :------------------------------------------------- | :-------------------------------------- | :--------------------------------------------------------- |
| `PUT`    | `/v1/management/objects/:collection/:externalId`   | `/v1/objects/:collection/:externalId`   | Cria ou atualiza (upsert) um objeto.                       |
| `GET`    | `/v1/management/objects/:collection/:externalId`   | `/v1/objects/:collection/:externalId`   | Recupera o perfil e propriedades de um objeto.             |
| `GET`    | `/v1/management/objects`                           | `/v1/objects`                           | Lista todos os objetos.                                    |
| `POST`   | `/v1/management/objects/:col/:extId/subscriptions` | `/v1/objects/:col/:extId/subscriptions` | Adiciona inscritos como observadores do objeto (máx. 100). |
| `DELETE` | `/v1/management/objects/:col/:extId/subscriptions` | `/v1/objects/:col/:extId/subscriptions` | Remove observadores do objeto.                             |
| `GET`    | —                                                  | `/v1/objects/:col/:extId/subscriptions` | Lista todos os inscritos que observam o objeto.            |

## Criar/Atualizar Objeto (Upsert)

Adiciona ou atualiza uma entidade de negócio.

```http
PUT /v1/management/objects/projects/proj_alpha
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json

{
  "name": "Project Alpha",
  "properties": {
    "status": "active",
    "ownerTeam": "engineering"
  }
}
```

- `:collection`: Deve ser alfanumérico em letras minúsculas com hífen/sublinhado (`^[a-z][a-z0-9_-]*$`, máx. 64 caracteres).
- `:externalId`: String de chave exclusiva da entidade (máx. 128 caracteres).
- `name`: Rótulo de exibição legível por humanos (máx. 256 caracteres).
- `properties`: Objeto opcional de metadados personalizados de chave-valor (máx. 50 chaves).

## Gerenciar Assinaturas

Gerencia quais inscritos observam o objeto.

### 1. Adicionar Assinaturas

Registra até 100 inscritos para observar o objeto. Os destinatários devem existir no ambiente:

```http
POST /v1/management/objects/projects/proj_alpha/subscriptions
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json

{
  "recipients": ["user_alice", "user_bob"],
  "properties": {
    "role": "editor"
  }
}
```

- `recipients`: Array de strings (contendo os `externalId`s dos inscritos) ou objetos contendo `{ "externalId": "..." }`.
- `properties`: Metadados opcionais específicos da assinatura.

### 2. Remover Assinaturas

Cancela o registro de observadores do objeto:

```http
DELETE /v1/management/objects/projects/proj_alpha/subscriptions
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json

{
  "recipients": ["user_bob"]
}
```

- `recipients`: Array de strings contendo os `externalId`s dos inscritos.

## Disparadores Fan-out (Envio em Leque)

Para notificar todos os inscritos que estão observando uma entidade, passe o objeto como destinatário em sua requisição de disparo de workflow:

```json
{
  "workflowName": "project.updated",
  "recipients": [
    {
      "collection": "projects",
      "id": "proj_alpha"
    }
  ]
}
```

## Limites

| Limite                                          | Valor             |
| :---------------------------------------------- | :---------------- |
| Máximo de objetos por ambiente                  | 5.000             |
| Máximo de observadores (assinaturas) por objeto | 10.000            |
| Tamanho máximo do lote para adicionar/remover   | 100 destinatários |
| Máximo de chaves de propriedades personalizadas | 50                |
