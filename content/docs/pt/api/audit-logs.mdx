# API de Audit Logs

Os logs de auditoria (audit logs) registram o histórico de workflows disparados e etapas de entrega, permitindo que você acompanhe o status exato e os detalhes do payload de cada mensagem.

---

## Autenticação e Acesso

- **Caminho base**: `/v1/audit-logs`
- **Auth**: Requer um token de sessão JWT do usuário.

---

## Resumo dos Endpoints

| Método | Caminho                                 | Descrição                                                                        |
| :----- | :-------------------------------------- | :------------------------------------------------------------------------------- |
| `GET`  | `/v1/audit-logs?environment=PRODUCTION` | Lista e filtra os logs de entrega (paginado, pesquisável).                       |
| `GET`  | `/v1/audit-logs/:id`                    | Obtém o status completo, entradas/saídas e métricas das etapas do ciclo de vida. |

---

## Listar Audit Logs

Recupera logs cronológicos correspondentes ao seu ambiente, filtros ou termo de busca.

```http
GET /v1/audit-logs?environment=PRODUCTION&page=1&limit=20&search=alex
Authorization: Bearer <jwt_dashboard_token>
```

### Filtros de Consulta

- `environment`: `DEVELOPMENT`, `STAGING` ou `PRODUCTION` (o padrão é `DEVELOPMENT`).
- `search`: Filtra por e-mail do inscrito, ID externo, ID do log ou nome do workflow (mínimo de 3 caracteres).
- `status`: Filtra por status de execução (por exemplo, `DELIVERED`, `FAILED`, `BOUNCED`).
- `channel`: Filtra por canal de entrega (por exemplo, `EMAIL`, `SMS`, `PUSH`, `WEBHOOK`).
- `timeRange`: Filtra usando predefinições: `1h`, `6h`, `24h`, `7d`, `30d`.
- `dateFrom` / `dateTo`: Filtros de intervalo de datas personalizados (strings ISO).
- `sortBy`: Campos: `executedAt`, `status`, `channel`, `retryCount`, `workflowName`, `subscriber`.
- `sortDir`: Ordem de ordenação: `asc` ou `desc` (o padrão é `desc`).

**Corpo da resposta:**

```json
{
  "logs": [
    {
      "id": "2db4c803-10ac-4bfa-8bf2-0cfb4db1b392",
      "executedAt": "2026-07-28T21:00:00.000Z",
      "channel": "EMAIL",
      "status": "DELIVERED",
      "retryCount": 0,
      "workflowName": "billing.invoice",
      "subscriber": {
        "externalId": "user_42",
        "email": "alex@example.com"
      }
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 20,
  "environment": "PRODUCTION",
  "sortBy": "executedAt",
  "sortDir": "desc"
}
```

## Obter Detalhes do Log de Entrega

Recupera informações completas de depuração, incluindo variáveis de payload e ciclos de vida de rastreamento.

```http
GET /v1/audit-logs/2db4c803-10ac-4bfa-8bf2-0cfb4db1b392
Authorization: Bearer <jwt_dashboard_token>
```
