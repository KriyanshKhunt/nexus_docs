# Integrações

O Nexus atua como um controlador de roteamento que se posiciona à frente das **suas próprias contas de provedores**. Configure as credenciais de API uma única vez na central de **Integrations** no painel de controle, e o Nexus cuidará do roteamento, failover, modelos (templates) e rastreamento de entregas.

---

## Camadas de Integração e Provedores

| Camada       | Chave                              | Provedores Suportados                           | Descrição                                             |
| :----------- | :--------------------------------- | :---------------------------------------------- | :---------------------------------------------------- |
| **Email**    | `email`                            | SendGrid, Resend, Amazon SES, Postmark, Mailgun | E-mails transacionais e de marketing                  |
| **SMS**      | `sms`                              | Twilio, Vonage, Plivo, Sinch                    | Alertas rápidos por SMS e OTPs                        |
| **WhatsApp** | `whatsapp`                         | Meta Cloud API, Twilio WhatsApp, Infobip        | Comunicação rica de chat B2C                          |
| **Push**     | `push`                             | Firebase Cloud Messaging (FCM), Apple APNs      | Notificações push móveis e web                        |
| **Chat**     | `slack` \| `discord` \| `ms_teams` | Slack, Discord, Microsoft Teams                 | Atualizações diretas em canais de chat                |
| **Webhooks** | `webhook`                          | Destinos de requisições HTTP personalizados     | Webhooks diretos de backend para backend              |
| **AI**       | `openai_ai` \| `anthropic_ai`      | OpenAI, Anthropic                               | Geração de conteúdo e nós de LLM em tempo de execução |

---

## Configuração de Pesos (Roteamento A/B)

Se você configurar múltiplas integrações para uma única camada, poderá dividir o tráfego entre elas definindo pesos personalizados:

```http
PUT /v1/integrations/weights/email
Authorization: Bearer <jwt_dashboard_token>
Content-Type: application/json

{
  "weights": {
    "sendgrid": 70,
    "resend": 30
  }
}
```

- **Camadas suportadas**: `email`, `sms`, `whatsapp`, `push`, `webhook`, `slack`, `discord`, `ms_teams`.
- **Validação**: A soma de todos os pesos dentro de uma camada deve totalizar exatamente **100**.

---

## Segurança

Todas as chaves de API, tokens e segredos de clientes dos provedores são criptografados no lado do servidor usando AES-256-GCM antes de serem gravados no banco de dados. A descriptografia ocorre apenas em nível de memória nos workers de execução ao despachar as entregas de saída.
