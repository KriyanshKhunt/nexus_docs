# Catálogo de Credenciais de Provedores

O Nexus Signal é executado utilizando as suas próprias conexões com as operadoras. Conecte qualquer um dos provedores suportados abaixo em **Settings → Integrations** no painel de controle. Todas as chaves são criptografadas em repouso utilizando o algoritmo AES-256-GCM.

---
