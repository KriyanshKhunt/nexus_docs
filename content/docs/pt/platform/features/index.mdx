## Nexus vs Plataformas Típicas

| Recurso                   | Nexus | Infraestrutura Típica   |
| :------------------------ | :---- | :---------------------- |
| Envio em leque de objetos | Sim   | Raro                    |
| Broadcasts pelo painel    | Sim   | Apenas Enterprise       |
| Nós HTTP Fetch / IA       | Sim   | Raro                    |
| Marca por tenant          | Sim   | Apenas Enterprise       |
| MCP + CLI                 | Sim   | Novidade em 2025+       |
| BYOP sem markup           | Sim   | Frequentemente embutido |

## Como os Recursos se Conectam

```mermaid
flowchart LR
  T(Gatilho) --> P{Presença?}
  P -->|Online| I(Apenas In-App)
  P -->|Offline| S(Smart timing)
  S --> W(Janela de entrega)
  W --> C(Despacho de canal)
  C --> F(Monitor de Failover)
```
