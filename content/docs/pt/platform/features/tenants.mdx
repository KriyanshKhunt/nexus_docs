# Marca por Tenant

Os **Tenants** (inquilinos) representam os _seus clientes_ dentro do Nexus (diferente da sua **Organização** do Nexus, que é o seu espaço de trabalho). Use tenants quando seu produto atender a várias empresas que precisam de e-mails com marca própria, feeds in-app delimitados e preferências de notificação isoladas.

<Callout type="info">
  Os tenants são um recurso **B2B**. Se sua aplicação for voltada ao consumidor final com uma marca
  única, você não precisará usar tenants.
</Callout>

## Modelo do Tenant

| Campo                   | Tipo   | Descrição                                                 |
| :---------------------- | :----- | :-------------------------------------------------------- |
| `externalId`            | string | ID do seu cliente (por exemplo, `"tenant_acme"`)          |
| `name`                  | string | Nome de exibição                                          |
| `branding.logo`         | string | URL do logotipo                                           |
| `branding.primaryColor` | string | Cor hexadecimal para elementos de destaque                |
| `branding.footerHtml`   | string | HTML personalizado de rodapé em layouts de e-mail         |
| `properties`            | object | Pares de chave-valor livres para metadados personalizados |

## Criar ou Atualizar um Tenant

Os tenants passam por upsert — chamar `upsert` usando um `externalId` existente atualizará seus campos.

**Node SDK:**

```ts
await nexus.tenants.upsert({
  externalId: 'tenant_acme',
  name: 'Acme Corp',
  branding: {
    logo: 'https://cdn.acme.io/logo.png',
    primaryColor: '#2563eb',
    footerHtml: '<p>© 2026 Acme Corp. Todos os direitos reservados.</p>',
  },
  properties: { tier: 'enterprise', region: 'us-east' },
});
```

**API de Gerenciamento (chave `sk_*`):**

```http
PUT /v1/management/tenants
Authorization: Bearer sk_prd_…
Content-Type: application/json

{
  "externalId": "tenant_acme",
  "name": "Acme Corp",
  "branding": {
    "logo": "https://cdn.acme.io/logo.png",
    "primaryColor": "#2563eb",
    "footerHtml": "<p>© 2026 Acme Corp</p>"
  }
}
```

## Disparar com Contexto de Tenant

Passe o `tenant` como uma string de `externalId` em qualquer disparo de workflow:

```ts
await nexus.workflows.trigger({
  workflowName: 'invoice.sent',
  tenant: 'tenant_acme',
  recipients: [{ externalId: 'user_42', email: 'billing@acme.io' }],
  data: { invoiceId: 'INV-001', amount: 4900 },
});
```

Quando um `tenant` é definido no gatilho:

- Os layouts de e-mail são compilados com as variáveis de marca do tenant (`{{ logo }}`, `{{ primaryColor }}`, etc.)
- As notificações in-app são delimitadas ao feed do tenant

## Como a Marca é Injetada nos Layouts de E-mail

Os campos de marca (branding) do tenant são propagados diretamente no contexto do modelo do Handlebars ao compilar os layouts de e-mail. Referencie-os por seus nomes de campos — **sem** o prefixo `branding.`:

```html
<!-- Em seu HTML de layout de e-mail -->
<img src="{{ logo }}" alt="{{ name }} logo" />
<div style="background-color: {{ primaryColor }};">{{{ content }}}</div>
{{{ footerHtml }}}
```

<Callout type="info">
`{{{ content }}}` (chaves triplas) renderiza o corpo do modelo de e-mail compilado como HTML puro dentro do layout. `{{ logo }}`, `{{ primaryColor }}` e `{{ footerHtml }}` são injetados a partir do objeto de branding do tenant.
</Callout>

## Feed de Notificação In-App Delimitado

Se você consultar a API bruta do SDK diretamente, poderá filtrar as notificações pelo UUID do banco de dados do tenant:

**API do SDK:**

```http
GET /v1/sdk/notifications?subscriberExternalId=user_42&tenantId=tenant_database_uuid
```

<Callout type="warn">
  O parâmetro de consulta `tenantId` do SDK exige o **UUID do banco de dados interno** do tenant, e
  não seu ID externo. Os componentes do SDK de frontend (React, Angular, JS) não oferecem suporte
  nativo para delimitar feeds por tenant. Use tags de tópicos do workflow se precisar de feeds de
  inbox delimitados por categorias simples na interface.
</Callout>

## Listar Tenants

```ts
const { data } = await nexus.tenants.list({ page: 1, limit: 25 });
```

## Limites

| Limite                           | Valor |
| :------------------------------- | :---- |
| Máximo de tenants por ambiente   | 1.000 |
| Máximo de campos de marca        | 20    |
| Máximo de chaves em `properties` | 50    |
