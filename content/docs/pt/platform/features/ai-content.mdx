# Geração de Conteúdo por IA

O editor de modelos no painel de controle inclui o **AI Assist** (Assistente de IA). Descreva o que a notificação deve dizer em linguagem simples e obtenha variações de redação otimizadas para os limites de caracteres de cada canal.

## Chaves de IA no Modelo BYOP (Bring Your Own Provider)

O Nexus não cobra taxas adicionais sobre o uso de tokens de IA. Você conecta sua própria chave de API em **Settings → Integrations** no painel de controle:

- **OpenAI** (`openai_ai`) — utiliza `gpt-4o-mini`
- **Anthropic** (`anthropic_ai`) — utiliza `claude-3-haiku-20240307`

As chamadas aos provedores são executadas no lado do servidor utilizando uma restrição de formato JSON. Se nenhuma chave de provedor estiver ativa, o gerador retornará um erro de validação `400`.

## Endpoint da API do Painel de Controle

A interface do painel de controle gera o conteúdo invocando o endpoint de modelos:

```http
POST /v1/templates/ai-generate
Authorization: Bearer <jwt_dashboard_token>
Content-Type: application/json
```

**Corpo da requisição:**

```json
{
  "prompt": "Order #4092 shipped with carrier DHL. Include tracking number.",
  "tone": "casual",
  "locale": "en"
}
```

- `prompt`: Descrição em texto simples do objetivo da mensagem (máx. 1.000 caracteres).
- `tone`: Tom do estilo visual. Deve ser `professional`, `casual`, `urgent` ou `friendly`. O padrão é `professional`.
- `locale`: Localidade de destino opcional. Se especificada, o LLM traduzirá e adaptará a redação para esse idioma.

**Corpo da resposta:**

```json
{
  "generated": {
    "email": {
      "subject": "Your order has shipped! 📦",
      "html": "Good news! Order #4092 is on its way. You can track your package with DHL..."
    },
    "sms": {
      "body": "Hi! Order #4092 has shipped via DHL. Track it here!"
    },
    "push": {
      "title": "Order Shipped!",
      "body": "Your order #4092 is on its way via DHL."
    },
    "whatsapp": {
      "body": "Good news! Order #4092 has shipped with DHL."
    },
    "slack": {
      "body": "Order #4092 has shipped with DHL."
    },
    "discord": {
      "body": "Order #4092 has shipped with DHL."
    },
    "ms_teams": {
      "body": "Order #4092 has shipped with DHL."
    }
  },
  "locale": "en",
  "message": "Content generated"
}
```

## Limites de Canais Aplicados

Todos os textos gerados são automaticamente truncados no lado do servidor para corresponder aos limites máximos de tamanho de cada canal de mensagens:

| Canal                   | Limite           | Campo gerado              |
| :---------------------- | :--------------- | :------------------------ |
| Email subject (Assunto) | 80 caracteres    | `generated.email.subject` |
| SMS body (Corpo)        | 160 caracteres   | `generated.sms.body`      |
| Push title (Título)     | 50 characters    | `generated.push.title`    |
| Push body (Corpo)       | 120 characters   | `generated.push.body`     |
| WhatsApp body (Corpo)   | 1.024 caracteres | `generated.whatsapp.body` |
| Slack body (Corpo)      | 2.000 caracteres | `generated.slack.body`    |
| Discord body (Corpo)    | 2.000 caracteres | `generated.discord.body`  |
| MS Teams body (Corpo)   | 2.000 caracteres | `generated.ms_teams.body` |

## Fluxo de Trabalho do Construtor de Modelos

1. Acesse **Templates** no painel de controle e crie ou abra um rascunho.
2. Clique na aba **AI Assist** na barra lateral.
3. Insira seu prompt, selecione o tom de sua preferência e marque os canais que deseja preencher.
4. Clique em **Generate** — o conteúdo gerado será exibido em uma visualização prévia.
5. Clique em **Apply to Draft** para mesclar as strings geradas diretamente nos campos do editor.
