# Node.js SDK

A biblioteca `@nexus-signal/node` fornece bindings do lado do servidor para disparar workflows, gerenciar tarefas agendadas (schedules), sincronizar inquilinos (tenants) e validar inscritos de forma segura.

---

## Instalação

Adicione o SDK ao seu projeto usando seu gerenciador de pacotes preferido:

<Tabs items={['npm', 'pnpm', 'yarn']}>

  <Tab value="pnpm">```bash pnpm add @nexus-signal/node ```</Tab>
  <Tab value="yarn">```bash yarn add @nexus-signal/node ```</Tab>
</Tabs>

## Inicialização do Cliente

Inicialize o `NexusClient` em seu servidor. Evite invocar este construtor repetidamente dentro de escopos de funções serverless; em vez disso, exporte uma única instância para aproveitar conexões keep-alive.

```ts title="lib/nexus.ts"
import { NexusClient } from '@nexus-signal/node';

export const nexus = new NexusClient({
  secretKey: process.env.NEXUS_SECRET_KEY!, // ex., sk_prd_...
  baseUrl: process.env.NEXUS_BASE_URL || 'https://api.nexussignal.dev',
  timeout: 5000,
});
```

## Disparando Workflows

Emite um gatilho de evento para iniciar seus caminhos de workflow visual configurados:

```ts title="routes/order.ts"
import { nexus } from '../lib/nexus';

export async function handleOrderShipped(orderId: string, userId: string) {
  const result = await nexus.workflows.trigger({
    workflowName: 'order.shipped',
    recipients: [
      {
        externalId: userId,
        email: 'customer@acme.io',
        phoneNumber: '+15550198234',
        timezone: 'America/New_York',
        locale: 'pt',
      },
    ],
    data: {
      orderNumber: orderId,
      shippingCarrier: 'FedEx',
      trackingLink: 'https://fedex.com/track/12345',
    },
  });

  if (!result.ok) {
    console.error('Trigger falhou:', result.error);
    if (result.queued) {
      console.warn('Payload armazenado em memória devido à abertura do disjuntor.');
    }
  }
}
```

## Geração Segura de HMAC

Gere uma assinatura criptograficamente segura para autenticar notificações de websocket:

```ts
// Retorna uma assinatura hexadecimal SHA-256 de 64 caracteres
const signature = nexus.auth.generateHmacSignature('user_active_99');
```

Como alternativa, você pode calcular isso sem inicializar o cliente:

```ts
import { generateHmacSignature } from '@nexus-signal/node';

const signature = generateHmacSignature(process.env.NEXUS_SECRET_KEY!, 'user_active_99');
```

## Tenants B2B e Personalização de Marca (Branding)

Gerencie modelos de e-mail white-label, estilos de tema in-app e preferências padrão para clientes corporativos distintos:

```ts
// Criar ou atualizar uma substituição de marca (branding) de tenant do cliente
const tenantResult = await nexus.tenants.upsert({
  externalId: 'tenant_acme_corp',
  name: 'Acme Corporation',
  branding: {
    logo: 'https://cdn.acme.io/logos/logo.png', // Chave de tipo estrita: logo
    primaryColor: '#0070f3',
    footerHtml: '<p>Enviado por Acme Corp, 123 Main St</p>',
  },
});

// Disparar um workflow limitado ao contexto de marca deste tenant
await nexus.workflows.trigger({
  workflowName: 'invoice.finalized',
  tenant: 'tenant_acme_corp',
  recipients: [{ externalId: 'alex_acme' }],
  data: { amount: '$450.00' },
});
```

## Inscrições de Entidades Compartilhadas (Objetos)

Envie mensagens para entidades virtuais (canais, quadros de documentos, projetos) e deixe o Nexus resolver as observações automaticamente:

```ts
// Definir a entidade
await nexus.objects.set({
  collection: 'workspaces',
  externalId: 'ws_eng_team',
  name: 'Engineering Workspace',
});

// Adicionar inscritos
await nexus.objects.addSubscriptions('workspaces', 'ws_eng_team', {
  recipients: ['usr_alice_dev', 'usr_bob_ops'],
});

// Notificar todos os observadores do workspace de engenharia
await nexus.workflows.trigger({
  workflowName: 'workspace.announcement',
  recipients: [{ collection: 'workspaces', id: 'ws_eng_team' }],
  data: { msg: 'Manutenção programada no banco de dados hoje à noite.' },
});
```

## Campanhas de Broadcast

Agende e envie campanhas para segmentos de inscritos pré-configurados:

```ts
const broadcast = await nexus.broadcasts.create({
  name: 'Platform Feature Update',
  workflowId: 'wf-uuid-goes-here',
  audienceId: 'aud-uuid-goes-here',
  data: { highlight: 'Condições de etapas dinâmicas já estão ativas!' },
});

if (broadcast.ok && broadcast.data?.broadcast?.id) {
  // Disparar a execução imediata do broadcast
  await nexus.broadcasts.send(broadcast.data.broadcast.id);
}
```

## Schedules Recurrentes

Configure despachos recorrentes de workflows de forma programática:

```ts
// Criar agendamento semanal para as segundas-feiras
await nexus.schedules.create({
  name: 'Weekly Usage Summary',
  workflowId: 'wf-uuid-goes-here',
  cronExpression: '0 9 * * 1', // Todas as segundas-feiras às 9:00 AM
  timezone: 'America/Los_Angeles',
  recipients: [{ externalId: 'user_analytics' }],
  data: { reportScope: 'seven_days' },
});

// Buscar agendamentos ativos
const list = await nexus.schedules.list({ page: 1, limit: 10 });

// Desativar ou excluir agendamentos
await nexus.schedules.update('schedule-uuid', { active: false });
await nexus.schedules.delete('schedule-uuid');
```

## Sincronização de Workflows Orientada a Código

Você pode sincronizar suas definições locais de workflows em TypeScript com a plataforma Nexus:

```ts
import { defineWorkflow } from '@nexus-signal/node';

const welcomeFlow = defineWorkflow('user.registration')
  .addChannel('IN_APP')
  .addDelay({ minutes: 15 })
  .addChannel('EMAIL')
  .toDefinition();

const result = await nexus.workflows.sync(welcomeFlow);
```

## Resiliência e Failover do Cliente

O SDK de Node inclui um **disjuntor** (circuit breaker) e um **buffer de memória** local para lidar com interrupções da plataforma:

- **Disjuntor**: Muda para o estado `OPEN` (aberto) após **5 falhas consecutivas** ou timeouts de solicitação. Durante este período, os gatilhos de saída são impedidos de fazer chamadas de rede e são enfileirados localmente. O circuito tenta se recuperar automaticamente após **60 segundos**.
- **Buffer de Memória**: Retém até **500 ações de gatilho** na memória local.
- **Liberação Manual (Flush)**: Se o cliente se recuperar, dispare essas tentativas armazenadas de volta para a plataforma usando `flushRetries()`.

```ts
const resilientClient = new NexusClient({
  secretKey: process.env.NEXUS_SECRET_KEY!,
  events: {
    onCircuitOpen: () => {
      console.warn('Disjuntor do Nexus aberto.');
    },
    onCircuitClose: async () => {
      console.info('Circuito do Nexus fechado. Liberando buffers...');
      await resilientClient.workflows.flushRetries();
    },
    onBufferOverflow: (failedPayload) => {
      console.error(
        'Buffer de memória local cheio! Payload descartado:',
        failedPayload.workflowName
      );
    },
  },
});
```
