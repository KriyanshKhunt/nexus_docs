A **Nexus CLI** envolve a [API de Gerenciamento](/docs/api/management) para gerenciar workflows, traduções e configurações a partir do terminal ou dentro de pipelines CI/CD.

## Instalação

Instale o pacote globalmente:

```bash
npm install -g @nexus-signal/cli
```

Ou execute comandos diretamente sem instalar:

```bash
npx @nexus-signal/cli --help
```

---

## Autenticação e Configuração Base

A CLI salva credenciais localmente para evitar a necessidade de autenticação em cada comando.

### Fazer login

Autentique-se em um workspace do Nexus. Isso salva sua chave secreta em `~/.nexus-signal/config.json`.

```bash
nexus login
# O prompt interativo solicitará sua chave sk_...
```

Para autenticar diretamente em um único comando ou script:

```bash
nexus login --key sk_prd_your_secret_key --url https://api.nexussignal.dev
```

### Exibir Identidade

Verifique o estado da conexão e a validade da chave:

```bash
nexus whoami
```

### Fazer logout

Exclua as credenciais em cache do seu sistema local:

```bash
nexus logout
```

### Substituições de Ambiente

Substitua credenciais armazenadas (ideal para ambientes CI/CD):

```bash
export NEXUS_SECRET_KEY=sk_prd_your_secret_key
export NEXUS_BASE_URL=https://api.nexussignal.dev
```

## Referência de Comandos

Todos los comandos suportam a flag `--json` para imprimir JSON diretamente em `stdout`.

### 1. Workflows

Crie, baixe e sincronize caminhos de notificação definidos por código.

- **Listar workflows**:
  ```bash
  nexus workflows list
  ```
- **Visualizar estrutura do workflow**:
  ```bash
  nexus workflows get order.shipped
  ```
- **Baixar definições**: Salva workflows remotos localmente em arquivos `.nexus/workflows/*.json`.
  ```bash
  nexus workflows pull --all
  nexus workflows pull --dir ./custom-workflows-path
  ```
- **Enviar definições**: Faz o upload das definições JSON locais dentro de `.nexus/workflows/` de volta para a plataforma.
  ```bash
  nexus workflows push --all
  nexus workflows push --dir ./custom-workflows-path
  ```
- **Disparar workflow**: Executa um workflow para os IDs de destinatários especificados.
  ```bash
  nexus workflows trigger order.shipped --to user_42,user_43 --data '{"orderId": "123"}' --tenant tenant_acme
  ```

---

### 2. Assinantes

Gerencie os destinatários de seus workflows de notificação.

- **Listar assinantes**: Pesquise ou filtre destinatários.
  ```bash
  nexus subscribers list --search alice --page 1 --limit 20
  ```
- **Obter detalhes**: Busca perfis de assinantes.
  ```bash
  nexus subscribers get user_42
  ```
- **Criar / Atualizar**: Realiza o upsert de campos de contato do assinante.
  ```bash
  nexus subscribers create --externalId user_42 --email billing@acme.io --phone +1234567890 --locale es --timezone America/New_York
  ```
- **Excluir assinante**: Auxiliar de limpeza em conformidade com o GDPR. Requer confirmação explícita.
  ```bash
  nexus subscribers delete user_42 --confirm
  ```

---

### 3. Objetos e Assinaturas

Gerencie entidades que não são usuários (como projetos, equipes ou pastas) para notificações em leque (fan-out).

- **Listar objetos**: Busca coleções configuradas.
  ```bash
  nexus objects list
  nexus objects list --collection projects
  ```
- **Salvar objeto (Upsert)**: Configura detalhes para uma entidade que não é um usuário.
  ```bash
  nexus objects set --collection projects --id proj_alpha --name "Project Alpha" --properties '{"status": "active"}'
  ```
- **Inscrever destinatários**: Inscreve usuários para acompanhar um objeto. Todos os assinantes são notificados quando este objeto é disparado.
  ```bash
  nexus objects subscribe --collection projects --id proj_alpha --subscribers user_42,user_43
  ```

---

### 4. Tenants B2B

Gerencie configurações de isolamento de marca branca, matrizes de preferência e substituições de marca para contas multi-tenant.

- **Listar tenants**:
  ```bash
  nexus tenants list
  ```
- **Salvar tenant**: Crie ou edite configurações multi-tenant.
  ```bash
  nexus tenants set --externalId tenant_acme --name "Acme Corp" --branding '{"logoUrl": "https://cdn.acme.io/logo.png", "primaryColor": "#2563eb"}'
  ```

---

### 5. Audiências

Agrupe assinantes dinamicamente com base em regras de segmentação.

- **Listar audiências**: Visualiza segmentos.
  ```bash
  nexus audiences list
  ```
- **Criar audiência**: Cria segmentos usando condições de filtragem.
  ```bash
  nexus audiences create --name "Inactive Users" --filters '[{"field": "globalUnsubscribed", "operator": "is_false"}]' --description "Non-unsubscribed subscribers"
  ```

---

### 6. Broadcasts

Agende ou envie workflows de notificação única para audiências.

- **Listar broadcasts**: Visualiza o status e a contagem de destinatários.
  ```bash
  nexus broadcasts list
  ```
- **Criar broadcast**: Prepara o envio de um workflow para uma audiência.
  ```bash
  nexus broadcasts create --name "Q3 Update" --workflowId <workflow-uuid> --audienceId <audience-uuid> --scheduledAt "2026-10-01T12:00:00Z"
  ```
- **Disparar broadcast**: Envia um broadcast criado imediatamente.
  ```bash
  nexus broadcasts send <broadcast-uuid>
  ```

---

### 7. Guias no Produto

Consulte definições de banners, badges e modais qualificados.

- **Listar guias**: Verifica guias in-app configuradas.
  ```bash
  nexus guides list
  ```
- **Obter detalhes**: Busca o JSON de configuração da guia.
  ```bash
  nexus guides get <guide-uuid>
  ```

---

### 8. Layouts de Email

Gerencie templates HTML de envoltório de email programaticamente.

- **Listar layouts**: Lista os layouts de envoltório disponíveis.
  ```bash
  nexus layouts list
  ```
- **Subir layout**: Faz upload de um template de envoltório de email (requer o marcador de posição `{{{content}}}`).
  ```bash
  nexus layouts push --name transactional-layout --file ./templates/layout.html --default
  ```

---

### 9. Traduções (i18n)

Gerencie pacotes de dicionário localizados para layouts de email.

- **Listar pacotes de tradução**:
  ```bash
  nexus translations list
  ```
- **Baixar traduções**: Baixa traduções remotas BCP 47 localmente para arquivos dentro de `.nexus/translations/`.
  ```bash
  nexus translations pull --dir ./custom-locales-path
  ```
- **Subir tradução**: Envia um arquivo JSON de chave-valor local para um local específico.
  ```bash
  nexus translations push --locale es --file ./locales/es.json --namespace billing
  ```

---

### 10. Utilitários e Agendamentos

Verifique conexões, execute diagnósticos de integridade, consulte logs de execução e acompanhe cronogramas.

- **Verificar conectividade**: Executa diagnósticos de ping.
  ```bash
  nexus health
  ```
- **Envio Rápido**: Atalho de envio direto de workflow para um único destinatário.
  ```bash
  nexus send order.shipped --to user_42 --data '{"orderId": "123"}' --tenant tenant_acme
  ```
- **Inspecionar logs**: Busca o status de um ID de log de execução.
  ```bash
  nexus logs <logId>
  ```
- **Listar agendamentos**: Mapeia workflows cron recorrentes ativos.
  ```bash
  nexus schedules list
  ```

## Piping e Scripting

O formato de saída `--json` facilita a integração da CLI com utilitários de script como `jq` e `xargs`:

```bash
# Listar todos os nomes de workflows
nexus workflows list --json | jq -r '.[].name'

# Extrair estados de entrega com erro dos destinatários
nexus logs <logId> --json | jq '.deliverySteps[].error'
```

Se um comando for bem-sucedido, a CLI sai com código `0`. Se falhar, sai com código `1`.

## Integração com CI/CD

Você pode integrar a CLI em seus pipelines do GitHub Actions para deploys automatizados:

```yaml
name: Deploy Notifications

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Deploy Nexus Workflows
        run: npx @nexus-signal/cli workflows push --all
        env:
          NEXUS_SECRET_KEY: ${{ secrets.NEXUS_SECRET_KEY }}
          NEXUS_BASE_URL: https://api.nexussignal.dev
```
