# SDK JS Headless

A biblioteca `@nexus-signal/js` é um wrapper de cliente agnóstico de framework para notificações in-app, preferências e guias. Ela utiliza ambientes de execução de navegadores puros (raw browser), tornando-a ideal para aplicações em **Vue 3**, **Svelte**, **SolidJS** ou **Vanilla JS** sem restrições de estilos de UI embutidos.

## Opções de Inicialização

Crie uma nova instância do cliente no carregamento do cliente:

```ts
import { NexusClient } from '@nexus-signal/js';

const nexus = new NexusClient({
  publicKey: 'pk_prd_your_public_key', // pk_dev_... ou pk_prd_...
  subscriberId: 'user_active_99',
  hmacSignature: 'computed_hmac_hex_signature',
  apiBaseUrl: 'https://api.nexussignal.dev',
});

// Iniciar transporte WebSocket e buscar estados iniciais
await nexus.connect();
```

## Eventos do Emissor

Registre callbacks de listener para alterações de estado em tempo real. O método `.on()` retorna uma função de limpeza para cancelar a assinatura (un-subscription).

```ts
// Ouvir novas mensagens
const unsubscribe = nexus.on('notification.received', (notification) => {
  console.log('Nova notificação recebida:', notification.title);
  alert(`Alerta: ${notification.body}`);
});

// Desvincular listeners ao destruir o componente
unsubscribe();
```

## Instâncias de Sub-Clientes

O `NexusClient` hospeda namespaces dedicados para gerenciar estruturas subjacentes:

### 1. Inboxes (`nexus.notifications`)

Gerencia listas, estados de leitura e filtros de tags:

```ts
// Buscar notificações ativas
const list = nexus.notifications.items; // Array de notificações atuais
const count = nexus.notifications.unread; // Contagem de não lidas

// Atualizar estados
await nexus.notifications.markRead('log-uuid-here');
await nexus.notifications.markAllRead();
await nexus.notifications.archive('log-uuid-here');

// Filtrar feed por tags
await nexus.notifications.refetch({ tags: ['billing'] });
```

### 2. Guias (`nexus.guides`)

Busque e dispense banners ou modais do painel:

```ts
// Buscar guias limitados ao caminho atual
await nexus.guides.fetch({ pathname: window.location.pathname });

const activeGuides = nexus.guides.guides;

// Acionar eventos de visualização e ação
await nexus.guides.markSeen('guide-uuid-here');
await nexus.guides.markInteracted('guide-uuid-here');
await nexus.guides.dismiss('guide-uuid-here');
```

### 3. Preferências (`nexus.preferences`)

Busque e atualize as escolhas de canais:

```ts
// Carregar preferências
await nexus.preferences.fetch();

const topics = nexus.preferences.topics;
const settings = nexus.preferences.preferences; // ex. { topic_id: { EMAIL: true } }

// Atualizar o valor de uma preferência
await nexus.preferences.updatePreference('billing_topic_id', 'EMAIL', false);
```

## Exemplos de Integração com Frameworks

### 1. Vue 3 (Composition API)

```vue title="components/NotificationFeed.vue"
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue';
import { NexusClient } from '@nexus-signal/js';

const props = defineProps<{ hmac: string; userId: string }>();

const nexus = new NexusClient({
  publicKey: 'pk_dev_your_public_key',
  subscriberId: props.userId,
  hmacSignature: props.hmac,
});

const unreadCount = ref(0);
const messages = ref<any[]>([]);
let countUnsub: () => void;

onMounted(async () => {
  await nexus.connect();
  unreadCount.value = nexus.notifications.unread;
  messages.value = nexus.notifications.items;

  // Vincular atualizações reativas
  countUnsub = nexus.on('notifications.count_changed', (count) => {
    unreadCount.value = count;
    messages.value = [...nexus.notifications.items];
  });
});

onUnmounted(() => {
  if (countUnsub) countUnsub();
  nexus.disconnect();
});
</script>

<template>
  <div class="inbox">
    <span>Notificações não lidas: {{ unreadCount }}</span>
    <div v-for="msg in messages" :key="msg.logId" class="item">
      <h6>{{ msg.title }}</h6>
      <button @click="nexus.notifications.markRead(msg.logId)">Marcar como lida</button>
    </div>
  </div>
</template>
```
