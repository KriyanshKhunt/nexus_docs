# React SDK

O pacote `@nexus-signal/react` fornece componentes de UI prontos para uso e hooks do React para incorporar centros de notificações, menus de preferências e mensagens de toast em sua aplicação React.

## NexusProvider

Envolva sua árvore React com o `NexusProvider` para configurar o contexto do seu workspace. Coloque este wrapper abaixo dos layouts de autenticação para garantir que as chaves estejam carregadas.

```tsx title="app/layout.tsx"
import { NexusProvider } from '@nexus-signal/react';

export function RootLayout({ children, user, hmac }: RootProps) {
  return (
    <NexusProvider
      publicKey={process.env.NEXT_PUBLIC_NEXUS_PUBLIC_KEY!} // pk_dev_... ou pk_prd_...
      subscriberId={user.externalId}
      hmacSignature={hmac}
      backendUrl="https://api.nexussignal.dev"
    >
      {children}
    </NexusProvider>
  );
}
```

## Suíte de Componentes

Monte componentes pré-estilizados baseados em Radix no seu layout:

### 1. Sino do Centro de Notificações

Renderiza um sino de notificação padrão com listeners WebSocket em tempo real, um emblema (badge) de contagem pulsante e uma lista de feed em popover.

```tsx title="components/header.tsx"
import { NotificationCenterBell } from '@nexus-signal/react';

export function Header() {
  return (
    <header className="flex justify-between items-center px-4 py-2 border-b">
      <h3>Meu Painel</h3>
      <NotificationCenterBell position="bottom-end" variant="ghost" />
    </header>
  );
}
```

### 2. Inbox de Página Completa

Um layout de feed completo com cabeçalhos de data, ações de ler/arquivar e rolagem infinita:

```tsx title="pages/notifications.tsx"
import { NotificationInbox } from '@nexus-signal/react';

export default function NotificationsPage() {
  return (
    <main className="max-w-2xl mx-auto py-8">
      <h2>Suas Notificações</h2>
      <NotificationInbox />
    </main>
  );
}
```

Para limitar os banners a tags de tópicos específicas (por exemplo, extratos de cobrança, alertas):

```tsx
<NotificationInbox tag="billing" maxItems={50} />
```

### 3. Matriz de Preferências

Expõe controles de alternância de inclusão/exclusão (opt-in/opt-out) para que os inscritos gerenciem seus canais de notificação por tópico:

```tsx title="pages/settings.tsx"
import { SubscriberPreferenceMatrix } from '@nexus-signal/react';

export default function Settings() {
  return (
    <section className="p-6 bg-card rounded-md">
      <h4>Canais de Notificação</h4>
      <SubscriberPreferenceMatrix variant="borderless" />
    </section>
  );
}
```

## Hook de Layout Personalizado (`useNotifications`)

Para layouts personalizados, use o hook de estado headless:

```tsx title="components/custom-inbox.tsx"
import { useNotifications } from '@nexus-signal/react';

export function CustomInbox() {
  const { items, unread, status, loadMore, hasMore, markRead } = useNotifications();

  return (
    <div>
      <p>
        Não lidas: {unread} | Conexão: {status}
      </p>
      <div className="space-y-2">
        {items.map((msg) => (
          <div
            key={msg.logId}
            className={`p-3 border rounded ${msg.read ? 'bg-muted' : 'font-bold'}`}
            onClick={() => msg.logId && markRead(msg.logId)}
          >
            <h5>{msg.title}</h5>
            <p>{msg.body}</p>
          </div>
        ))}
      </div>
      {hasMore && <button onClick={loadMore}>Carregar Mais</button>}
    </div>
  );
}
```

## Hook de Interceptação de Guias (`useGuides`)

Gerencie gatilhos de banners e tooltips dentro da sua aplicação React dinamicamente:

```tsx
import { useGuides } from '@nexus-signal/react';

export function AppGuideSlots() {
  const { guides, markSeen, dismiss } = useGuides({
    pathname: window.location.pathname,
  });

  return guides.map((guide) => (
    <div key={guide.id} className="p-4 border border-blue-200 bg-blue-50 rounded">
      <h6>{guide.content.title}</h6>
      <p>{guide.content.body}</p>
      <button onClick={() => markSeen(guide.id)}>Entendido</button>
      <button onClick={() => dismiss(guide.id)}>Dispensar</button>
    </div>
  ));
}
```

## Personalização de Estilos e Temas

Os componentes usam variáveis CSS compatíveis com estilos personalizados e alternadores de modo escuro (dark mode). Substitua-os em sua folha de estilos CSS global:

```css title="styles/global.css"
:root {
  /* Fundos de painel */
  --nexus-theme-panel: #ffffff;
  --nexus-theme-panel-muted: #f9fafb;

  /* Tipografia */
  --nexus-theme-text: #111827;
  --nexus-theme-muted: #6b7280;

  /* Bordas e linhas */
  --nexus-theme-border: #e5e7eb;
  --nexus-theme-border-subtle: #f3f4f6;

  /* Destaques de destaque (pontos não lidos, caixas de seleção ativas) */
  --nexus-theme-accent: #2563eb;
  --nexus-theme-accent-foreground: #ffffff;
  --nexus-theme-muted-bg: #f9fafb;
}

[data-theme='dark'] {
  --nexus-theme-panel: #1f2937;
  --nexus-theme-panel-muted: #111827;
  --nexus-theme-text: #f9fafb;
  --nexus-theme-muted: #9ca3af;
  --nexus-theme-border: #374151;
  --nexus-theme-border-subtle: #1f2937;
  --nexus-theme-accent: #3b82f6;
  --nexus-theme-accent-foreground: #ffffff;
  --nexus-theme-muted-bg: #111827;
}
```
