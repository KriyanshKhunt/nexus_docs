El servidor **Model Context Protocol (MCP)** permite que los asistentes de codificación de IA (como Cursor, Claude Desktop y Windsurf) gestionen workflows, suscriptores, objetos, broadcasts y guías directamente desde tu editor utilizando lenguaje natural.

---

## Instalación y configuración en el IDE

Configura el servidor en el archivo de configuración de MCP de tu editor.

### Variables de Entorno

| Variable           | Requerido | Descripción                               | Por defecto             |
| :----------------- | :-------- | :---------------------------------------- | :---------------------- |
| `NEXUS_SECRET_KEY` | **Sí**    | Tu clave secreta API del entorno (`sk_*`) |                         |
| `NEXUS_BASE_URL`   | No        | URL base del endpoint de la API           | `http://localhost:5000` |

---

### Archivos de Configuración

#### 1. Claude Desktop

Añade la configuración a tus ajustes globales:

- **macOS / Linux**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "nexus-signal": {
      "command": "npx",
      "args": ["-y", "@nexus-signal/mcp-server@latest"],
      "env": {
        "NEXUS_SECRET_KEY": "sk_prd_your_secret_key",
        "NEXUS_BASE_URL": "https://api.nexussignal.dev"
      }
    }
  }
}
```

#### 2. Cursor

Ve a **Settings → Features → MCP**, haz clic en **Add New MCP Server** y configura:

- **Name**: `nexus-signal`
- **Type**: `command`
- **Command**: `npx -y @nexus-signal/mcp-server@latest`
- **Environment Variables**: Añade `NEXUS_SECRET_KEY` y `NEXUS_BASE_URL` como pares clave-valor.

#### 3. Windsurf

Añade la configuración a `~/.codeium/windsurf/mcp_config.json`:

````json
{
  "mcpServers": {
    "nexus-signal": {
Add the configuration to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "nexus-signal": {
      "command": "npx",
      "args": ["-y", "@nexus-signal/mcp-server@latest"],
````

## Primitivas de MCP

El servidor expone **30 herramientas**, **4 recursos** y **5 prompts** para permitir que los LLMs exploren y ejecuten configuraciones de notificación.

### 1. Herramientas (Tools)

Las herramientas permiten a los agentes de IA realizar operaciones de lectura y escritura en tu espacio de trabajo:

#### Workflows

- `nexus_list_workflows` — Lista workflows en el entorno actual.
- `nexus_get_workflow` — Obtiene la configuración de pasos de un workflow por nombre.
- `nexus_trigger_workflow` — Dispara un workflow para múltiples destinatarios.
- `nexus_send_notification` — Envía un workflow a un único destinatario.
- `nexus_sync_workflows` — Sube definiciones de workflows declaradas en código.
- `nexus_get_delivery_status` — Inspecciona el estado de entrega de un UUID de registro.

#### Suscriptores

- `nexus_list_subscribers` — Busca destinatarios.
- `nexus_get_subscriber` — Obtiene detalles del suscriptor por ID.
- `nexus_create_subscriber` — Realiza un upsert de los campos de contacto del suscriptor.
- `nexus_delete_subscriber` — Purga el suscriptor y su historial.

#### Objetos

- `nexus_set_object` — Crea o actualiza una entidad que no sea un usuario.
- `nexus_get_object` — Obtiene detalles del objeto y el recuento de suscriptores.
- `nexus_subscribe_to_object` — Añade suscriptores para observar un objeto.
- `nexus_unsubscribe_from_object` — Da de baja a los destinatarios de un objeto.

#### Tenants B2B

- `nexus_list_tenants` — Obtiene las personalizaciones de marca de los tenants.
- `nexus_create_or_update_tenant` — Realiza un upsert de la configuración de un tenant.

#### Audiencias y Segmentos

- `nexus_list_audiences` — Obtiene segmentos de audiencia dinámicos.
- `nexus_create_audience` — Crea un segmento con reglas lógicas.

#### Broadcasts

- `nexus_list_broadcasts` — Consulta los broadcasts y sus estados.
- `nexus_create_broadcast` — Prepara un envío de workflow a una audiencia.
- `nexus_send_broadcast` — Entrega un broadcast inmediatamente.

#### Contenido y Layouts

- `nexus_list_layouts` — Obtiene layouts de envoltura HTML de correo.
- `nexus_create_or_update_layout` — Crea un layout de correo compartido.
- `nexus_list_translations` — Lista los paquetes de localización.
- `nexus_upsert_translation` — Crea o actualiza el diccionario clave-valor de traducción local.

#### Guías en la aplicación (In-App)

- `nexus_list_guides` — Lista configuraciones de guías integradas en la app (banners, modales, tooltips).
- `nexus_get_guide` — Obtiene el esquema de diseño de una guía.
- `nexus_create_or_update_guide` — Realiza un upsert de atributos de la guía.

#### Schedules y Sistema

- `nexus_list_schedules` — Lista workflows cron recurrentes activos.
- `nexus_check_health` — Verifica el estado de conectividad con la API.

---

### 2. Recursos (Resources)

Los recursos proporcionan documentos de contexto de solo lectura a los modelos de IA:

- `nexus://docs/integration-guide` — Ejemplos de inicio rápido para Node.js.
- `nexus://docs/step-types` — Esquemas de referencia para delay, digest, channel y httpFetch.
- `nexus://docs/channels` — Canales compatibles y campos de contacto requeridos.
- `nexus://workflows/{name}` — Esquema JSON en vivo de un workflow configurado.

---

### 3. Prompts

Los prompts actúan como plantillas preconfiguradas que ayudan a los modelos a orquestar tareas:

- `setup-transactional-workflow` — Ayuda a diseñar rutas transaccionales con fallback de canales y delays.
- `setup-digest-workflow` — Prepara la agrupación de notificaciones y resúmenes de correo/in-app.
- `setup-escalation-workflow` — Crea cadenas de escalado (`in-app` → `email` → `SMS`) según prioridad.
- `setup-object-fanout` — Crea objetos, añade suscriptores y dispara workflows.
- `debug-delivery` — Guía al modelo para depurar entregas fallidas mediante IDs de registro y preferencias.
