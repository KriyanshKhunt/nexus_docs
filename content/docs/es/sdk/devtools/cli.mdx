La **CLI de Nexus** envuelve la [API de Gestión](/docs/api/management) para administrar flujos de trabajo (workflows), traducciones y configuraciones desde la terminal o dentro de pipelines de CI/CD.

## Instalación

Instala el paquete de forma global:

```bash
npm install -g @nexus-signal/cli
```

O ejecuta comandos al vuelo sin necesidad de instalar:

```bash
npx @nexus-signal/cli --help
```

---

## Autenticación y Configuración Base

La CLI guarda las credenciales localmente para evitar tener que especificarlas en cada comando.

### Iniciar sesión

Autentícate en un espacio de trabajo de Nexus. Esto guarda tu clave secreta en `~/.nexus-signal/config.json`.

```bash
nexus login
# El indicador interactivo te solicitará tu clave sk_...
```

Para autenticarte directamente en un solo comando o script:

```bash
nexus login --key sk_prd_your_secret_key --url https://api.nexussignal.dev
```

### Mostrar Identidad

Verifica el estado de la conexión y la validez de tu clave:

```bash
nexus whoami
```

### Cerrar sesión

Elimina las credenciales almacenadas de tu sistema local:

```bash
nexus logout
```

### Anulaciones de Entorno

Inyecta variables para anular credenciales guardadas (ideal para entornos de CI/CD):

```bash
export NEXUS_SECRET_KEY=sk_prd_your_secret_key
export NEXUS_BASE_URL=https://api.nexussignal.dev
```

## Referencia de Comandos

Todos los comandos soportan la bandera `--json` para imprimir JSON directamente en la salida estándar `stdout`.

### 1. Workflows

Crea, descarga y sincroniza rutas de notificación definidas en código.

- **Listar workflows**:
  ```bash
  nexus workflows list
  ```
- **Ver estructura de un workflow**:
  ```bash
  nexus workflows get order.shipped
  ```
- **Descargar definiciones**: Guarda los flujos de trabajo remotos localmente en archivos dentro de `.nexus/workflows/*.json`.
  ```bash
  nexus workflows pull --all
  ```
- **Subir definiciones**: Sube las definiciones JSON locales dentro de `.nexus/workflows/` de vuelta a la plataforma.
  ```bash
  nexus workflows push --all
  ```
- **Disparar workflow**: Ejecuta un flujo de trabajo para las IDs de destinatarios especificadas.
  ```bash
  nexus workflows trigger order.shipped --to user_42,user_43 --data '{"orderId": "123"}' --tenant tenant_acme
  ```

---

### 2. Suscriptores

Gestiona los destinatarios de tus flujos de trabajo de notificación.

- **Listar suscriptores**: Busca o filtra destinatarios.
  ```bash
  nexus subscribers list --search alice --page 1 --limit 20
  ```
- **Ver detalles**: Obtén los perfiles de los suscriptores.
  ```bash
  nexus subscribers get user_42
  ```
- **Crear / Actualizar**: Realiza un upsert de los campos de contacto de un suscriptor.
  ```bash
  nexus subscribers create --externalId user_42 --email billing@acme.io --phone +1234567890 --locale es --timezone America/New_York
  ```
- **Eliminar suscriptor**: Depura información del suscriptor cumpliendo normativas como GDPR. Requiere confirmación explícita.
  ```bash
  nexus subscribers delete user_42 --confirm
  ```

---

### 3. Objetos y Suscripciones

Gestiona entidades que no son usuarios (como proyectos, equipos o carpetas) para notificaciones masivas en abanico (fan-out).

- **Listar objetos**: Obtén colecciones configuradas.
  ```bash
  nexus objects list
  nexus objects list --collection projects
  ```
- **Guardar objeto (Upsert)**: Configura detalles para una entidad que no sea un usuario.
  ```bash
  nexus objects set --collection projects --id proj_alpha --name "Project Alpha" --properties '{"status": "active"}'
  ```
- **Suscribir destinatarios**: Añade suscriptores para observar un objeto. Todos ellos serán notificados cuando este objeto sea disparado.
  ```bash
  nexus objects subscribe --collection projects --id proj_alpha --subscribers user_42,user_43
  ```

---

### 4. Tenants B2B

Gestiona la configuración de aislamiento de marca blanca, matrices de preferencias y anulaciones de branding para cuentas multi-tenant.

- **Listar tenants**:
  ```bash
  nexus tenants list
  ```
- **Guardar tenant**: Crea o edita configuraciones multi-tenant.
  ```bash
  nexus tenants set --externalId tenant_acme --name "Acme Corp" --branding '{"logoUrl": "https://cdn.acme.io/logo.png", "primaryColor": "#2563eb"}'
  ```

---

### 5. Audiencias

Agrupa suscriptores de forma dinámica en función de reglas de segmentación.

- **Listar audiencias**: Visualiza segmentos creados.
  ```bash
  nexus audiences list
  ```
- **Crear audiencia**: Crea segmentos utilizando condiciones de filtrado.
  ```bash
  nexus audiences create --name "Inactive Users" --filters '[{"field": "globalUnsubscribed", "operator": "is_false"}]' --description "Non-unsubscribed subscribers"
  ```

---

### 6. Broadcasts

Programa o envía flujos de trabajo de notificación masiva única a audiencias.

- **Listar broadcasts**: Consulta el estado y cantidad de destinatarios.
  ```bash
  nexus broadcasts list
  ```
- **Crear broadcast**: Prepara un envío de flujo de trabajo a una audiencia específica.
  ```bash
  nexus broadcasts create --name "Q3 Update" --workflowId <workflow-uuid> --audienceId <audience-uuid> --scheduledAt "2026-10-01T12:00:00Z"
  ```
- **Enviar broadcast**: Despega y entrega un broadcast creado inmediatamente.
  ```bash
  nexus broadcasts send <broadcast-uuid>
  ```

---

### 7. Guías en el Producto

Consulta las definiciones elegibles de banners, badges y modales.

- **Listar guías**: Revisa las guías activas configuradas en la app.
  ```bash
  nexus guides list
  ```
- **Obtener detalles**: Obtén el esquema JSON de configuración de una guía.
  ```bash
  nexus guides get <guide-uuid>
  ```

---

### 8. Layouts de Email

Administra plantillas de envoltura HTML de correo electrónico de forma programática.

- **Listar layouts**: Muestra los layouts de envoltura disponibles.
  ```bash
  nexus layouts list
  ```
- **Subir layout**: Sube una plantilla de envoltorio de email (requiere el marcador de posición `{{{content}}}`).
  ```bash
  nexus layouts push --name transactional-layout --file ./templates/layout.html --default
  ```

---

### 9. Traducciones (i18n)

Gestiona diccionarios de traducción localizados para las plantillas.

- **Listar paquetes de traducción**:
  ```bash
  nexus translations list
  ```
- **Descargar traducciones**: Descarga traducciones remotas BCP 47 localmente en archivos dentro de `.nexus/translations/`.
  ```bash
  nexus translations pull --dir ./custom-locales-path
  ```
- **Subir traducción**: Sube un archivo JSON local de clave-valor para un locale específico.
  ```bash
  nexus translations push --locale es --file ./locales/es.json --namespace billing
  ```

---

### 10. Utilidades y Schedules

Verifica conexiones, ejecuta diagnósticos, consulta registros de ejecución y haz seguimiento de tareas programadas.

- **Verificar conectividad**: Ejecuta diagnósticos de ping.
  ```bash
  nexus health
  ```
- **Envío rápido (Quick Send)**: Envío directo de flujo de trabajo de forma abreviada a un solo destinatario.
  ```bash
  nexus send order.shipped --to user_42 --data '{"orderId": "123"}' --tenant tenant_acme
  ```
- **Inspeccionar registros**: Busca el estado de un identificador de registro de entrega.
  ```bash
  nexus logs <logId>
  ```
- **Listar schedules**: Muestra los flujos de trabajo programados cron recurrentes.
  ```bash
  nexus schedules list
  ```

## Piping y Scripting

El formato de salida `--json` facilita la integración de la CLI con herramientas de scripting como `jq` y `xargs`:

```bash
# Listar todos los nombres de workflows
nexus workflows list --json | jq -r '.[].name'

# Extraer errores de los pasos de entrega de destinatarios fallidos
nexus logs <logId> --json | jq '.deliverySteps[].error'
```

Si un comando se ejecuta correctamente, la CLI finaliza con código `0`. Si falla, finaliza con código `1`.

## Integración con CI/CD

Puedes integrar la CLI en tus flujos de trabajo de GitHub Actions para despliegues automatizados:

```yaml
name: Deploy Notifications

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Deploy Nexus Workflows
        run: npx @nexus-signal/cli workflows push --all
        env:
          NEXUS_SECRET_KEY: ${{ secrets.NEXUS_SECRET_KEY }}
          NEXUS_BASE_URL: https://api.nexussignal.dev
```
