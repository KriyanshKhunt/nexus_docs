# SDK de JS Headless

La librería `@nexus-signal/js` es una envoltura de cliente independiente de framework para notificaciones integradas en la aplicación (in-app), preferencias y guías. Utiliza entornos de navegador nativos, lo que la hace ideal para aplicaciones en **Vue 3**, **Svelte**, **SolidJS** o **Vanilla JS** sin dependencias ni restricciones de estilos de UI empaquetadas.

---

## Opciones de inicialización

Crea una nueva instancia de cliente al cargar el cliente:

```ts
import { NexusClient } from '@nexus-signal/js';

const nexus = new NexusClient({
  publicKey: 'pk_prd_your_public_key', // pk_dev_... o pk_prd_...
  subscriberId: 'user_active_99',
  hmacSignature: 'computed_hmac_hex_signature',
  apiBaseUrl: 'https://api.nexussignal.dev',
});

// Inicia el transporte de WebSocket y obtiene los estados iniciales
await nexus.connect();
```

## Eventos del emisor

Registra callbacks de escucha para cambios de estado en tiempo real. El método `.on()` devuelve una función de limpieza de desuscripción.

```ts
// Escucha nuevos mensajes
const unsubscribe = nexus.on('notification.received', (notification) => {
  console.log('Nueva notificación recibida:', notification.title);
  alert(`Alert: ${notification.body}`);
});

// Desvincula los listeners al destruir el componente
unsubscribe();
```

## Instancias de sub-clientes

El `NexusClient` aloja espacios de nombres dedicados para gestionar las estructuras subyentes:

### 1. Bandejas de entrada (`nexus.notifications`)

Gestiona listas, estados de lectura y filtros de etiquetas:

```ts
// Obtiene las notificaciones activas
const list = nexus.notifications.items; // Array de notificaciones actuales
const count = nexus.notifications.unread; // Conteo de no leídos

// Actualiza estados
await nexus.notifications.markRead('log-uuid-here');
await nexus.notifications.markAllRead();
await nexus.notifications.archive('log-uuid-here');

// Filtra el feed por etiquetas
await nexus.notifications.refetch({ tags: ['billing'] });
```

### 2. Guías (`nexus.guides`)

Obtén y descarta banners o modales del panel de control:

```ts
// Obtiene guías limitadas a la ruta actual
await nexus.guides.fetch({ pathname: window.location.pathname });

const activeGuides = nexus.guides.guides;

// Dispara eventos de vista y acción
await nexus.guides.markSeen('guide-uuid-here');
await nexus.guides.markInteracted('guide-uuid-here');
await nexus.guides.dismiss('guide-uuid-here');
```

### 3. Preferencias (`nexus.preferences`)

Obtén y actualiza las elecciones de canales:

```ts
// Carga preferencias
await nexus.preferences.fetch();

const topics = nexus.preferences.topics;
const settings = nexus.preferences.preferences; // ej. { topic_id: { EMAIL: true } }

// Actualiza un valor de preferencia
await nexus.preferences.updatePreference('billing_topic_id', 'EMAIL', false);
```

## Ejemplos de integración de frameworks

### 1. Vue 3 (Composition API)

```vue title="components/NotificationFeed.vue"
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue';
import { NexusClient } from '@nexus-signal/js';

const props = defineProps<{ hmac: string; userId: string }>();

const nexus = new NexusClient({
  publicKey: 'pk_dev_your_public_key',
  subscriberId: props.userId,
  hmacSignature: props.hmac,
});

const unreadCount = ref(0);
const messages = ref<any[]>([]);
let countUnsub: () => void;

onMounted(async () => {
  await nexus.connect();
  unreadCount.value = nexus.notifications.unread;
  messages.value = nexus.notifications.items;

  // Vincula actualizaciones reactivas
  countUnsub = nexus.on('notifications.count_changed', (count) => {
    unreadCount.value = count;
    messages.value = [...nexus.notifications.items];
  });
});

onUnmounted(() => {
  if (countUnsub) countUnsub();
  nexus.disconnect();
});
</script>

<template>
  <div class="inbox">
    <span>Notificaciones no leídas: {{ unreadCount }}</span>
    <div v-for="msg in messages" :key="msg.logId" class="item">
      <h6>{{ msg.title }}</h6>
      <button @click="nexus.notifications.markRead(msg.logId)">Marcar como leído</button>
    </div>
  </div>
</template>
```
