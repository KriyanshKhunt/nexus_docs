# SDK de React

El paquete `@nexus-signal/react` proporciona componentes de interfaz de usuario (UI) listos para usar y react hooks para incrustar centros de notificaciones, menús de preferencias y notificaciones flotantes (toast) dentro de tu aplicación de React.

---

## NexusProvider

Envuelve tu árbol de React con `NexusProvider` para configurar el contexto de tu espacio de trabajo. Coloca esta envoltura debajo de los layouts de autenticación para asegurar que las claves estén cargadas.

```tsx title="app/layout.tsx"
import { NexusProvider } from '@nexus-signal/react';

export function RootLayout({ children, user, hmac }: RootProps) {
  return (
    <NexusProvider
      publicKey={process.env.NEXT_PUBLIC_NEXUS_PUBLIC_KEY!} // pk_dev_... o pk_prd_...
      subscriberId={user.externalId}
      hmacSignature={hmac}
      backendUrl="https://api.nexussignal.dev"
    >
      {children}
    </NexusProvider>
  );
}
```

## Conjunto de componentes

Monta componentes basados en Radix pre-estilizados en tu layout:

### 1. Campana del Centro de Notificaciones

Renderiza una campana de notificación estándar con listeners de WebSocket en tiempo real, un badge de conteo intermitente y una lista de feed emergente (popover).

```tsx title="components/header.tsx"
import { NotificationCenterBell } from '@nexus-signal/react';

export function Header() {
  return (
    <header className="flex justify-between items-center px-4 py-2 border-b">
      <h3>My Dashboard</h3>
      <NotificationCenterBell position="bottom-end" variant="ghost" />
    </header>
  );
}
```

### 2. Inbox de página completa

Un diseño de feed completo con encabezados de fecha, acciones de leer/archivar e infinite scroll (desplazamiento infinito):

```tsx title="pages/notifications.tsx"
import { NotificationInbox } from '@nexus-signal/react';

export default function NotificationsPage() {
  return (
    <main className="max-w-2xl mx-auto py-8">
      <h2>Your Notifications</h2>
      <NotificationInbox />
    </main>
  );
}
```

Para limitar los mensajes a etiquetas de temas específicas (ej. estados de cuenta de facturación, alertas):

```tsx
<NotificationInbox tag="billing" maxItems={50} />
```

### 3. Matriz de preferencias

Expone controles de inclusión/exclusión (opt-in/opt-out) para que los suscriptores controlen sus canales de notificación por tema:

```tsx title="pages/settings.tsx"
import { SubscriberPreferenceMatrix } from '@nexus-signal/react';

export default function Settings() {
  return (
    <section className="p-6 bg-card rounded-md">
      <h4>Notification Channels</h4>
      <SubscriberPreferenceMatrix variant="borderless" />
    </section>
  );
}
```

## Hook de diseño personalizado (`useNotifications`)

Para diseños personalizados, utiliza el hook de estado sin interfaz:

```tsx title="components/custom-inbox.tsx"
import { useNotifications } from '@nexus-signal/react';

export function CustomInbox() {
  const { items, unread, status, loadMore, hasMore, markRead } = useNotifications();

  return (
    <div>
      <p>
        Unread: {unread} | Connection: {status}
      </p>
      <div className="space-y-2">
        {items.map((msg) => (
          <div
            key={msg.logId}
            className={`p-3 border rounded ${msg.read ? 'bg-muted' : 'font-bold'}`}
            onClick={() => msg.logId && markRead(msg.logId)}
          >
            <h5>{msg.title}</h5>
            <p>{msg.body}</p>
          </div>
        ))}
      </div>
      {hasMore && <button onClick={loadMore}>Load More</button>}
    </div>
  );
}
```

## Hook de intercepciones de guías (`useGuides`)

Administra los disparadores de banners y tooltips dentro de tu aplicación de React de forma dinámica:

```tsx
import { useGuides } from '@nexus-signal/react';

export function AppGuideSlots() {
  const { guides, markSeen, dismiss } = useGuides({
    pathname: window.location.pathname,
  });

  return guides.map((guide) => (
    <div key={guide.id} className="p-4 border border-blue-200 bg-blue-50 rounded">
      <h6>{guide.content.title}</h6>
      <p>{guide.content.body}</p>
      <button onClick={() => markSeen(guide.id)}>Got it</button>
      <button onClick={() => dismiss(guide.id)}>Dismiss</button>
    </div>
  ));
}
```
