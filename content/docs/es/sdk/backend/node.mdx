# SDK de Node.js

La librería `@nexus-signal/node` proporciona enlaces del lado del servidor para disparar workflows, administrar tareas programadas (schedules), sincronizar inquilinos (tenants) y validar suscriptores de forma segura.

---

## Instalación

Agrega el SDK a tu proyecto usando tu gestor de paquetes preferido:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab value="npm">```bash npm install @nexus-signal/node ```</Tab>
  <Tab value="pnpm">```bash pnpm add @nexus-signal/node ```</Tab>
  <Tab value="yarn">```bash yarn add @nexus-signal/node ```</Tab>
</Tabs>

## Inicialización del cliente

Inicializa el `NexusClient` en tu servidor. Evita invocar este constructor dentro del alcance de funciones serverless de forma repetida; en su lugar, exporta una sola instancia para aprovechar las conexiones keep-alive.

```ts title="lib/nexus.ts"
import { NexusClient } from '@nexus-signal/node';

export const nexus = new NexusClient({
  secretKey: process.env.NEXUS_SECRET_KEY!, // ej. sk_prd_...
  baseUrl: process.env.NEXUS_BASE_URL || 'https://api.nexussignal.dev',
  timeout: 5000,
});
```

## Disparar workflows

Emite un trigger de evento para iniciar tus rutas de workflows visuales configuradas:

```ts title="routes/order.ts"
import { nexus } from '../lib/nexus';

export async function handleOrderShipped(orderId: string, userId: string) {
  const result = await nexus.workflows.trigger({
    workflowName: 'order.shipped',
    recipients: [
      {
        externalId: userId,
        email: 'customer@acme.io',
        phoneNumber: '+15550198234',
        timezone: 'America/New_York',
        locale: 'en',
      },
    ],
    data: {
      orderNumber: orderId,
      shippingCarrier: 'FedEx',
      trackingLink: 'https://fedex.com/track/12345',
    },
  });

  if (!result.ok) {
    console.error('El disparador falló:', result.error);
    if (result.queued) {
      console.warn('Payload almacenado localmente en buffer debido a la apertura del circuito.');
    }
  }
}
```

## Generación segura de HMAC

Genera una firma criptográficamente segura para autenticar las notificaciones por websocket:

```ts
// Devuelve una firma hexadecimal SHA-256 de 64 caracteres
const signature = nexus.auth.generateHmacSignature('user_active_99');
```

Alternativamente, puedes calcular esto sin inicializar el cliente:

```ts
import { generateHmacSignature } from '@nexus-signal/node';

const signature = generateHmacSignature(process.env.NEXUS_SECRET_KEY!, 'user_active_99');
```

## Tenants B2B y personalización de marca

Administra plantillas de correo de marca blanca, estilos de temas integrados en la aplicación (in-app) y valores predeterminados de preferencias para diferentes clientes corporativos:

```ts
// Crea o actualiza una sobrescritura de personalización de marca de tenant de cliente
const tenantResult = await nexus.tenants.upsert({
  externalId: 'tenant_acme_corp',
  name: 'Acme Corporation',
  branding: {
    logo: 'https://cdn.acme.io/logos/logo.png', // Clave de tipo estricta: logo
    primaryColor: '#0070f3',
    footerHtml: '<p>Sent by Acme Corp, 123 Main St</p>',
  },
});

// Dispara un workflow limitado a este contexto de personalización de marca de tenant
await nexus.workflows.trigger({
  workflowName: 'invoice.finalized',
  tenant: 'tenant_acme_corp',
  recipients: [{ externalId: 'alex_acme' }],
  data: { amount: '$450.00' },
});
```

## Suscripciones de entidades compartidas (Objetos)

Envía mensajes a entidades virtuales (canales, tableros de documentos, proyectos) y deja que Nexus resuelva los observadores de forma automática:

```ts
// Define la entidad
await nexus.objects.set({
  collection: 'workspaces',
  externalId: 'ws_eng_team',
  name: 'Engineering Workspace',
});

// Agrega suscriptores
await nexus.objects.addSubscriptions('workspaces', 'ws_eng_team', {
  recipients: ['usr_alice_dev', 'usr_bob_ops'],
});

// Notifica a todos los observadores del espacio de trabajo de ingeniería
await nexus.workflows.trigger({
  workflowName: 'workspace.announcement',
  recipients: [{ collection: 'workspaces', id: 'ws_eng_team' }],
  data: { msg: 'Scheduled database maintanance tonight.' },
});
```

## Campañas de Broadcast

Programa y envía campañas a segmentos de suscriptores preconfigurados:

```ts
const broadcast = await nexus.broadcasts.create({
  name: 'Platform Feature Update',
  workflowId: 'wf-uuid-goes-here',
  audienceId: 'aud-uuid-goes-here',
  data: { highlight: 'Dynamic Step Conditions are live!' },
});

if (broadcast.ok && broadcast.data?.broadcast?.id) {
  // Despacha la ejecución inmediata del broadcast
  await nexus.broadcasts.send(broadcast.data.broadcast.id);
}
```

## Schedules recurrentes

Configura despachos de workflows recurrentes de forma programática:

```ts
// Crea una programación (schedule) recurrente para los lunes
await nexus.schedules.create({
  name: 'Weekly Usage Summary',
  workflowId: 'wf-uuid-goes-here',
  cronExpression: '0 9 * * 1', // Todos los lunes a las 9:00 AM
  timezone: 'America/Los_Angeles',
  recipients: [{ externalId: 'user_analytics' }],
  data: { reportScope: 'seven_days' },
});

// Obtiene las programaciones activas
const list = await nexus.schedules.list({ page: 1, limit: 10 });

// Desactiva o purga programaciones
await nexus.schedules.update('schedule-uuid', { active: false });
await nexus.schedules.delete('schedule-uuid');
```

## Sincronización de workflows orientada a código

Puedes sincronizar las definiciones locales de workflows en TypeScript con la plataforma Nexus:

```ts
import { defineWorkflow } from '@nexus-signal/node';

const welcomeFlow = defineWorkflow('user.registration')
  .addChannel('IN_APP')
  .addDelay({ minutes: 15 })
  .addChannel('EMAIL')
  .toDefinition();

const result = await nexus.workflows.sync(welcomeFlow);
```

## Resiliencia y failover del cliente

El SDK de Node incluye un **disyuntor (circuit breaker)** y un **buffer de memoria** local para manejar caídas de la plataforma:

- **Disyuntor (Circuit Breaker)**: Cambia al estado `OPEN` (abierto) después de **5 fallos consecutivos** o tiempos de espera agotados. Durante este periodo, se bloquean los triggers salientes de llamar a la red y se encolan localmente. El circuito intenta recuperarse de forma automática después de **60 segundos**.
- **Buffer de memoria**: Retiene hasta **500 acciones de trigger** en la memoria local.
- **Vaciado manual (Flush)**: Si el cliente se recupera, dispara estos reintentos de vuelta a la plataforma usando `flushRetries()`.

```ts
const resilientClient = new NexusClient({
  secretKey: process.env.NEXUS_SECRET_KEY!,
  events: {
    onCircuitOpen: () => {
      console.warn('El disyuntor de Nexus se abrió.');
    },
    onCircuitClose: async () => {
      console.info('El circuito de Nexus se cerró. Vaciando buffers...');
      await resilientClient.workflows.flushRetries();
    },
    onBufferOverflow: (failedPayload) => {
      console.error(
        '¡Buffer de memoria local lleno! Payload descartado:',
        failedPayload.workflowName
      );
    },
  },
});
```
