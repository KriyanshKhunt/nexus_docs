El editor de plantillas del panel de control incluye **AI Assist**. Describe en texto simple lo que debe decir la notificación y obtén variaciones de copy optimizadas para los límites de caracteres de cada canal.

---

## BYOP (Bring Your Own Provider) — Claves de IA propias

Nexus no aplica margen de beneficio al uso de tokens de IA. Conecta tu propia clave de API en **Settings → Integrations** en el panel de control:

- **OpenAI** (`openai_ai`) — usa `gpt-4o-mini`
- **Anthropic** (`anthropic_ai`) — usa `claude-3-haiku-20240307`

Las llamadas al proveedor se ejecutan en el lado del servidor utilizando una restricción de formato JSON. Si no hay ninguna clave de proveedor activa, el generador devuelve un error de validación `400`.

---

## Endpoint de la API del panel de control

La interfaz de usuario del panel genera el copy invocando el endpoint de plantillas:

```http
POST /v1/templates/ai-generate
Authorization: Bearer <jwt_dashboard_token>
Content-Type: application/json
```

**Cuerpo de la solicitud:**

```json
{
  "prompt": "Order #4092 shipped with carrier DHL. Include tracking number.",
  "tone": "casual",
  "locale": "en"
}
```

- `prompt`: Descripción en texto simple del objetivo del mensaje (máximo 1,000 caracteres).
- `tone`: Tono del estilo visual. Debe ser `professional`, `casual`, `urgent` o `friendly`. Por defecto es `professional`.
- `locale`: Idioma destino opcional. Si se especifica, el LLM traduce y adapta el copy a ese idioma.

**Cuerpo de la respuesta:**

```json
{
  "generated": {
    "email": {
      "subject": "Your order has shipped! 📦",
      "html": "Good news! Order #4092 is on its way. You can track your package with DHL..."
    },
    "sms": {
      "body": "Hi! Order #4092 has shipped via DHL. Track it here!"
    },
    "push": {
      "title": "Order Shipped!",
      "body": "Your order #4092 is on its way via DHL."
    },
    "whatsapp": {
      "body": "Good news! Order #4092 has shipped with DHL."
    },
    "slack": {
      "body": "Order #4092 has shipped with DHL."
    },
    "discord": {
      "body": "Order #4092 has shipped with DHL."
    },
    "ms_teams": {
      "body": "Order #4092 has shipped with DHL."
    }
  },
  "locale": "en",
  "message": "Content generated"
}
```

## Límites de canal aplicados

Todos los outputs generados se truncan automáticamente en el servidor para ajustarse a los límites de tamaño máximo de cada canal de mensajería:

| Canal              | Límite           | Campo generado            |
| :----------------- | :--------------- | :------------------------ |
| Asunto de email    | 80 caracteres    | `generated.email.subject` |
| Cuerpo de SMS      | 160 caracteres   | `generated.sms.body`      |
| Título de push     | 50 caracteres    | `generated.push.title`    |
| Cuerpo de push     | 120 caracteres   | `generated.push.body`     |
| Cuerpo de WhatsApp | 1,024 caracteres | `generated.whatsapp.body` |
| Cuerpo de Slack    | 2,000 caracteres | `generated.slack.body`    |
| Cuerpo de Discord  | 2,000 caracteres | `generated.discord.body`  |
| Cuerpo de MS Teams | 2,000 caracteres | `generated.ms_teams.body` |

## Flujo de trabajo en el editor de plantillas

1. Ve a **Templates** en el panel de control y crea o abre un borrador.
2. Haz clic en la pestaña **AI Assist** en la barra lateral.
3. Introduce tu prompt, selecciona el tono que prefieras y elige los canales que deseas rellenar.
4. Haz clic en **Generate** — se mostrará una vista previa del contenido del borrador.
5. Haz clic en **Apply to Draft** para combinar las cadenas generadas directamente en los campos del editor.
