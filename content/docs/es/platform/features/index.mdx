## Nexus vs plataformas típicas

| Funcionalidad             | Nexus | Infraestructura típica         |
| ------------------------- | ----- | ------------------------------ |
| Fan-out de objetos        | Sí    | Poco común                     |
| Broadcasts desde el panel | Sí    | Solo enterprise                |
| Nodos HTTP Fetch / IA     | Sí    | Poco común                     |
| Branding por tenant       | Sí    | Solo enterprise                |
| MCP + CLI                 | Sí    | Nuevo en 2025+                 |
| BYOP sin margen           | Sí    | A menudo incluido en el precio |

## Cómo se conectan las funcionalidades

```mermaid
flowchart LR
  T[Trigger] --> P{¿Presencia?}
  P -->|En línea| I[Solo In-App]
  P -->|Fuera de línea| S[Temporización inteligente]
  S --> W[Ventana de entrega]
  W --> C[Despacho de canal]
  C --> F[Vigilancia de failover]
```
