title: Integraciones

Nexus actúa como un controlador de enrutamiento que se sitúa delante de **tus propias cuentas de proveedor**. Configura las credenciales de la API una vez en el hub de **Integrations** del panel de control, y Nexus gestiona el enrutamiento, el failover, las plantillas y el seguimiento de entregas.

---

## Capas de integración y proveedores

| Capa         | Clave                              | Proveedores admitidos                           | Descripción                                                |
| :----------- | :--------------------------------- | :---------------------------------------------- | :--------------------------------------------------------- |
| **Email**    | `email`                            | SendGrid, Resend, Amazon SES, Postmark, Mailgun | Emails transaccionales y de marketing                      |
| **SMS**      | `sms`                              | Twilio, Vonage, Plivo, Sinch                    | Alertas SMS rápidas y OTPs                                 |
| **WhatsApp** | `whatsapp`                         | Meta Cloud API, Twilio WhatsApp, Infobip        | Comunicaciones ricas B2C por chat                          |
| **Push**     | `push`                             | Firebase Cloud Messaging (FCM), Apple APNs      | Notificaciones push web y móvil                            |
| **Chat**     | `slack` \| `discord` \| `ms_teams` | Slack, Discord, Microsoft Teams                 | Actualizaciones directas en el workspace de chat           |
| **Webhooks** | `webhook`                          | Destinos HTTP personalizados                    | Webhooks directos backend-a-backend                        |
| **IA**       | `openai_ai` \| `anthropic_ai`      | OpenAI, Anthropic                               | Generación de contenido y nodos LLM en tiempo de ejecución |

---

## Configuración de pesos (Enrutamiento A/B)

Si configuras múltiples integraciones para una sola capa, puedes dividir el tráfico entre ellas estableciendo pesos personalizados:

```http
PUT /v1/integrations/weights/email
Authorization: Bearer <jwt_dashboard_token>
Content-Type: application/json

{
  "weights": {
    "sendgrid": 70,
    "resend": 30
  }
}
```

- **Capas admitidas**: `email`, `sms`, `whatsapp`, `push`, `webhook`, `slack`, `discord`, `ms_teams`.
- **Validación**: Todos los pesos dentro de una capa deben sumar exactamente **100**.

---

## Seguridad

Todas las claves de API, tokens y secretos de cliente de los proveedores se cifran en el servidor utilizando AES-256-GCM antes de escribirse en la base de datos. El descifrado ocurre únicamente a nivel de memoria en los threads del worker al despachar entregas salientes.
