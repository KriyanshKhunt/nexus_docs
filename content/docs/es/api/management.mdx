---
title: API de Gestión
description: Endpoints del lado del servidor y herramientas de desarrollo para gestionar workflows, programaciones, entornos y plantillas de forma programática.
---

La **API de Gestión** alimenta los comandos de sincronización de la CLI, las integraciones de CI/CD y las conexiones de servicio de MCP. Todas las rutas requieren credenciales de clave secreta.

---

## Autenticación y acceso

- **Ruta base**: `/v1/management`
- **Autenticación**: Pasa tu clave secreta específica del entorno como un token Bearer:
  `Authorization: Bearer sk_prd_your_secret_key`

---

## Recursos del espacio de trabajo

### 1. Workflows

- `GET /v1/management/workflows`: Lista todas las claves y nodos de workflows configurados en el entorno.
- `GET /v1/management/workflows/:name`: Obtiene detalles de un workflow por su nombre de máquina.

### 2. Suscriptores

- `GET /v1/management/subscribers`: Lista los perfiles de suscriptores (paginados, buscables).
- `GET /v1/management/subscribers/:id`: Obtiene los detalles de un suscriptor por su UUID de base de datos.
- `POST /v1/management/subscribers`: Registra o identifica a un suscriptor.
- `DELETE /v1/management/subscribers/:id`: Purga a un suscriptor (cumplimiento de GDPR).

### 3. Tenants B2B

- `GET /v1/management/tenants`: Lista los tenants B2B.
- `PUT /v1/management/tenants`: Actualiza o crea (upsert) configuraciones de branding de tenants.

### 4. Segmentos de audiencia

- `GET /v1/management/audiences`: Lista definiciones de audiencias.
- `POST /v1/management/audiences`: Crea filtros de segmento.

### 5. Broadcasts

- `GET /v1/management/broadcasts`: Lista todas las campañas.
- `POST /v1/management/broadcasts`: Crea un borrador o un broadcast programado.
- `POST /v1/management/broadcasts/:id/send`: Dispara el envío inmediato de un broadcast.

### 6. Guías dentro del producto

- `GET /v1/management/guides`: Lista las campañas de guías activas.
- `GET /v1/management/guides/:id`: Obtiene los detalles de una guía.
- `POST /v1/management/guides`: Registra una campaña de guía.
- `PUT /v1/management/guides/:id`: Actualiza el contenido o la segmentación de una guía.

### 7. Objetos de entidad

- `GET /v1/management/objects`: Lista los objetos observados.
- `PUT /v1/management/objects/:collection/:externalId`: Registra o actualiza (upsert) un objetivo de observación en la base de datos.
- `GET /v1/management/objects/:collection/:externalId`: Recupera un objetivo de observación de objeto.
- `POST /v1/management/objects/:collection/:externalId/subscriptions`: Suscribe observadores.
- `DELETE /v1/management/objects/:collection/:externalId/subscriptions`: Cancela la suscripción de observadores.

### 8. Plantillas y layouts de email

- `GET /v1/management/email/layouts`: Lista los layouts HTML personalizados.
- `POST /v1/management/email/layouts`: Sube un nuevo layout HTML de contenedor.

### 9. Traducciones

- `GET /v1/management/translations`: Lista los paquetes de idiomas subidos.
- `PUT /v1/management/translations`: Sube el mapeo de traducciones JSON de locale.

### 10. Schedules (Programaciones)

- `GET /v1/management/schedules`: Lista todas las tareas programadas activas.

## Rastreo de logs de entrega

Recupera los resultados de entrega detallados y los logs para fines de auditoría:

```http
GET /v1/management/logs/2db4c803-10ac-4bfa-8bf2-0cfb4db1b392
Authorization: Bearer sk_prd_your_secret_key
```
