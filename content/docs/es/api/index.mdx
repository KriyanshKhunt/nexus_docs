## Modos de autenticación

| Audiencia             | Auth                         | Endpoints                                                 |
| --------------------- | ---------------------------- | --------------------------------------------------------- |
| Aplicaciones servidor | `Authorization: Bearer sk_*` | `/workflows/trigger`, `/workflows/sync`, `/schedules/sdk` |
| SDK de navegador      | `x-nexus-public-key: pk_*`   | `/sdk/*`                                                  |
| Panel de control      | JWT session / Bearer         | `/workflows/dashboard`, `/broadcasts`, `/audiences`, etc. |
| CLI / MCP             | `Authorization: Bearer sk_*` | `/management/*`                                           |

## Convenciones de respuesta

- Los triggers devuelven **202 Accepted** (procesamiento asíncrono)
- Los errores devuelven `{ error: string, code?: string, details?: object }`
- Los límites de tasa (rate limits) se aplican según el nivel de plan
