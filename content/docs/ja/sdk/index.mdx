## 統合アーキテクチャフロー

次の図は、サーバー側の発送、ユーザーエージェントソケット、および外部プロバイダーのリレーの間のトランザクション境界を示しています。

```mermaid
flowchart TD
  subgraph Server Environment [サーバー環境]
    App[アプリサーバー] -->|1. sk_* でSDKを初期化| SDK[Node.js SDK]
    SDK -->|2. ワークフローをトリガー| API[Nexus REST API]
    SDK -->|3. HMAC署名を生成| App
  end

  subgraph Client Environment [クライアント環境]
    App -->|4. subscriberId + HMACを渡す| FE[ブラウザアプリケーション]
    FE -->|5. pk_* でWebSocket接続| WebHost[Socket.IO ゲートウェイ]
  end

  subgraph Background Processing [バックグラウンド処理]
    API -->|6. ジョブをキューイング| Q[(Redisキュー)]
    Q -->|7. ワーカーによる処理| Workers[非同期ワーカー]
    Workers -->|8. ライブイベントの送信| WebHost
    Workers -->|9. プロバイダーの呼び出し| Carriers[プロバイダー (Twilio/SendGrid)]
  end

  WebHost -->|10. フィードへのストリーム配信| FE
```

## パッケージ互換性マトリクス

ターゲットのランタイムが最小環境要件を満たしていることを確認してください。

| パッケージ名前空間             | コアランタイム    | ピア依存関係（Peer Deps）   | 主な役割                                                                       |
| :----------------------------- | :---------------- | :-------------------------- | :----------------------------------------------------------------------------- |
| **`@nexus-signal/node`**       | Node.js >= 18.0.0 | なし（ネイティブ Fetch）    | バックエンドのトリガー、スケジュール、オブジェクトの同期、ワークフローの同期。 |
| **`@nexus-signal/react`**      | React >= 18.0.0   | `socket.io-client >= 4.8.0` | スタイル適用済みのベル、フルページフィード、環境設定。                         |
| **`@nexus-signal/js`**         | ES6 / HTML5       | `socket.io-client >= 4.8.0` | フレームワークに依存しないストアハンドラー、WebSocket エミッター。             |
| **`@nexus-signal/angular`**    | Angular >= 17.0.0 | `socket.io-client >= 4.8.0` | リアクティブな Signals、スタンドアロンコンポーネントラッパー。                 |
| **`@nexus-signal/cli`**        | Node.js >= 18.0.0 | なし                        | ローカルスキーマの同期、CI/CD プロモーションパイプライン。                     |
| **`@nexus-signal/mcp-server`** | Node.js >= 18.0.0 | なし                        | AI コーディングアシスタント用の自然言語によるツール呼び出し。                  |

## インストール方法

アプリケーションの統合箇所に応じてライブラリをインストールします。

<Tabs items={['サーバー側', 'React クライアント', '開発ツール']}>
  <Tab value="サーバー側">
    バックエンドルートからトリガーを実行し、ワークフローを同期する場合：
    ```bash
    npm install @nexus-signal/node
    ```
  </Tab>
  <Tab value="React クライアント">
    React ツリー内にアプリ内通知センターとユーザー設定をマウントする場合：
    ```bash
    npm install @nexus-signal/react socket.io-client
    ```
  </Tab>
  <Tab value="開発ツール">
    ローカルの同期メカニズムを使用するか、MCP インスタンスを起動する場合：
    ```bash
    # CLIをグローバルにインストール
    npm install -g @nexus-signal/cli

    # MCPサーバーをその場で実行
    npx -y @nexus-signal/mcp-server@latest
    ```

  </Tab>
</Tabs>

<Callout type="warn">
  **キー露出ルール**: `sk_`
  で始まるシークレットキーは、クライアント側のコード、シングルページアプリケーション（SPA）、またはバンドルスクリプトには決して埋め込まないでください。パブリックなルートでは、必ずサーバー側で生成された
  HMAC 署名によって検証されたパブリックキー（`pk_`）を使用する必要があります。
</Callout>
