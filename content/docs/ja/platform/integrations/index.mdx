---
title: インテグレーション
description: 独自のメール、SMS、プッシュ通知、Webhook、チャット、および AI プロバイダーを Nexus Signal に接続します。
---

Nexus は、**お客様自身のプロバイダーアカウント**の前面に配置されるルーティングコントローラーとして機能します。ダッシュボードの **Integrations** ハブで一度 API 認証情報を構成するだけで、Nexus がルーティング、フェイルオーバー、テンプレート、および配信追跡を処理します。

---

## インテグレーションレイヤー & プロバイダー

| レイヤー     | キー                               | サポートされるプロバイダー                      | 説明                                              |
| :----------- | :--------------------------------- | :---------------------------------------------- | :------------------------------------------------ |
| **Email**    | `email`                            | SendGrid, Resend, Amazon SES, Postmark, Mailgun | トランザクションメールおよびマーケティングメール  |
| **SMS**      | `sms`                              | Twilio, Vonage, Plivo, Sinch                    | 高速な SMS アラートと OTP（ワンタイムパスワード） |
| **WhatsApp** | `whatsapp`                         | Meta Cloud API, Twilio WhatsApp, Infobip        | リッチな B2C チャットコミュニケーション           |
| **Push**     | `push`                             | Firebase Cloud Messaging (FCM), Apple APNs      | Web およびモバイルのプッシュ通知                  |
| **Chat**     | `slack` \| `discord` \| `ms_teams` | Slack, Discord, Microsoft Teams                 | チャットワークスペースへの直接のアップデート      |
| **Webhooks** | `webhook`                          | カスタム HTTP フェッチターゲット                | ダイレクトなサーバー間 Webhook                    |
| **AI**       | `openai_ai` \| `anthropic_ai`      | OpenAI, Anthropic                               | コンテンツ生成 & 実行時 LLM ノード                |

---

## 重み付け構成（A/B ルーティング）

単一のレイヤーに対して複数のインテグレーションを構成する場合、カスタムの比率（重み）を設定してトラフィックを分散させることができます。

```http
PUT /v1/integrations/weights/email
Authorization: Bearer <jwt_dashboard_token>
Content-Type: application/json

{
  "weights": {
    "sendgrid": 70,
    "resend": 30
  }
}
```

- **サポートされるレイヤー**: `email`、`sms`、`whatsapp`、`push`、`webhook`、`slack`、`discord`、`ms_teams`。
- **バリデーション**: レイヤー内のすべての重みの合計は正確に **100** になる必要があります。

---

## セキュリティ

すべてのプロバイダーの API キー、トークン、およびクライアントシークレットは、データベースに書き込まれる前にサーバー側で AES-256-GCM を使用して暗号化されます。復号は、外部への発送時にワーカープロセスのメモリ上でのみ実行されます。
