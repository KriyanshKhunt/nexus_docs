## 本番環境へ移行する前に

<Accordions type="single">
  <Accordion title="開発環境（Development）でテストを行いましたか？">
    本番環境のプロバイダーキーを接続する前に、必ず開発環境とサンドボックスシミュレーターを使用してください。
  </Accordion>
  <Accordion title="プロバイダー資格情報は本番環境のみに設定されていますか？">
    ステージング環境は本番環境をミラーリングできますが、Git にコミットされるローカルの `.env`
    ファイルで本番環境のキーを再利用しないでください。
  </Accordion>
  <Accordion title="HMAC はサーバー側で生成されていますか？">
    クライアント SDK セッションには、バックエンドから生成された新しい HMAC 署名が必要です。詳細は
    [認証](/docs/platform/getting-started/authentication) を参照してください。
  </Accordion>
  <Accordion title="オブジェクトファンアウトとブロードキャストのテストを行いましたか？">
    製品メッセージング機能を使用している場合は、まずステージング環境でオーディエンスの解決とオブジェクト購読を検証してください。
  </Accordion>
</Accordions>
