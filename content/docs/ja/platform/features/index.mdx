## Nexus と一般的な通知プラットフォームの比較

| 機能                         | Nexus    | 一般的なインフラ     |
| :--------------------------- | :------- | :------------------- |
| オブジェクトファンアウト     | **対応** | ほとんどなし         |
| ダッシュボードからの送信     | **対応** | エンタープライズ限定 |
| HTTP Fetch / AI ノード       | **対応** | ほとんどなし         |
| テナントごとのブランディング | **対応** | エンタープライズ限定 |
| MCP + CLI                    | **対応** | 2025年以降の新機能   |
| BYOP（手数料なし）           | **対応** | パック料金に含まれる |

## 機能同士の連携フロー

```mermaid
flowchart LR
  T(トリガー) --> P{アクティブ状況判定?}
  P -->|オンライン| I(アプリ内通知のみ)
  P -->|オフライン| S(最適なタイミング)
  S --> W(配信時間枠の確認)
  W --> C(各チャネルへの送信)
  C --> F(フェイルオーバー監視)
```
