翻訳データ（Translations）は、言語ロケールと名前空間によってマッピングされた、静的なキー・値の文字列テーブルです。これにより、トリガー実行時にワークフローがローカライズされた文字列を動的に挿入（補間）できます。

---

## アクセス & パス

- **サーバー間 / SDK 用（`sk_*` 認証）**: ルートパスは `/v1/management/translations`
- **ダッシュボード画面用（JWT 認証）**: ルートパスは `/v1/translations`

---

## エンドポイント概要

| メソッド | 管理用パス (`sk_*`)           | ダッシュボード用パス (JWT) | 説明                                               |
| :------- | :---------------------------- | :------------------------- | :------------------------------------------------- |
| `GET`    | `/v1/management/translations` | `/v1/translations`         | 環境内のすべての翻訳パッケージの一覧を取得します。 |
| `PUT`    | `/v1/management/translations` | `/v1/translations`         | 翻訳パッケージを作成または更新（Upsert）します。   |
| `GET`    | —                             | `/v1/translations/:id`     | UUID 指定で翻訳パッケージの詳細を取得します。      |
| `DELETE` | —                             | `/v1/translations/:id`     | 翻訳パッケージを削除します。                       |

---

## 翻訳パッケージの保存 (アップサート)

翻訳テーブルをアップロードまたは更新します。

```http
PUT /v1/management/translations
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json

{
  "locale": "es-MX",
  "namespace": "invoice-labels",
  "content": {
    "title.invoice_overdue": "Factura Vencida",
    "button.pay_now": "Pagar Ahora",
    "description.amount_due": "El monto total a pagar es {{amount}}."
  }
}
```

### リクエストボディのフィールド

- `locale`: string (必須)。BCP 47 形式の言語コード（最大35文字、例: `es-MX`、`ja`、`pt-BR`）。
- `namespace`: string (任意)。大文字小文字を区別するカテゴリ分け用ラベル（最大64文字）。英小文字、数字、ダッシュ、アンダースコア（`/^[a-z][a-z0-9_-]*$/`）。デフォルト値は `default`。
- `content`: object (必須)。文字列のキーと値のペアで構成されるフラットな辞書（最大 500 キー）。
  - **キー**: 先頭文字は英字で、英数字、ドット、アンダースコア、またはダッシュを含むもの（`/^[a-zA-Z][a-zA-Z0-9_.-]*$/`、最大128文字）。
  - **値**: 生のテンプレート文字列（最大 5,000 文字）。Handlebars の変数スロットを含めることができます。

## 翻訳ファイルの一覧取得

```http
GET /v1/management/translations
Authorization: Bearer sk_prd_your_secret_key
```

**レスポンスボディ:**

```json
{
  "translations": [
    {
      "id": "2db4c803-10ac-4bfa-8bf2-0cfb4db1b392",
      "locale": "es-MX",
      "namespace": "invoice-labels",
      "keyCount": 3,
      "createdAt": "2026-07-28T12:00:00.000Z",
      "updatedAt": "2026-07-28T21:00:00.000Z"
    }
  ]
}
```

## 制限事項

| 制限事項                         | 値         |
| :------------------------------- | :--------- |
| 環境あたりの最大翻訳パッケージ数 | 50         |
| 翻訳ファイルあたりの最大キー数   | 500        |
| キーの最大長さ                   | 128 文字   |
| 値の最大長さ                     | 5,000 文字 |
| 名前空間の最大長さ               | 64 文字    |
