# Nexus Signal API

**ベース URL:** `https://api.nexussignal.dev/v1`

トリガー、製品メッセージング、アプリ内受信箱、および分析へのプログラムアクセスを提供します。取り込み用エンドポイントは **202 Accepted** を返します — 配信は非同期処理されます。

## 認証モード

| 対象           | 認証方法                     | 使用エンドポイント                                        |
| :------------- | :--------------------------- | :-------------------------------------------------------- |
| サーバーアプリ | `Authorization: Bearer sk_*` | `/workflows/trigger`、`/workflows/sync`、`/schedules/sdk` |
| ブラウザ SDK   | `x-nexus-public-key: pk_*`   | `/sdk/*`                                                  |
| ダッシュボード | JWT セッション / Bearer      | `/workflows/dashboard`、`/broadcasts`、`/audiences` など  |
| CLI / MCP      | `Authorization: Bearer sk_*` | `/management/*`                                           |

## レスポンス規約

- トリガーは **202 Accepted** を返します（非同期処理）
- エラーは `{ error: string, code?: string, details?: object }` を返します
- レート制限はプランのティアごとに適用されます
