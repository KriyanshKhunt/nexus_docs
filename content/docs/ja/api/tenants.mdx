ダッシュボードベースパス: `/v1/tenants`

管理API (CLI/MCP): `GET|PUT /v1/management/tenants`

## テナントのリスト表示

```http
GET /v1/tenants
Authorization: Bearer <jwt>
```

## テナントの保存 (Upsert)

```http
PUT /v1/tenants
Authorization: Bearer <jwt>
```

```json
{
  "externalId": "tenant_acme",
  "name": "Acme Corp",
  "branding": {
    "logoUrl": "https://cdn.acme.io/logo.png",
    "primaryColor": "#2563eb",
    "footerHtml": "<p>© Acme</p>"
  },
  "providerOverrides": {},
  "preferenceDefaults": {}
}
```

## 取得 / 更新 / 削除

```http
GET    /v1/tenants/:id
PATCH  /v1/tenants/:id
DELETE /v1/tenants/:id
```

## テナント付きトリガー

```json
{
  "workflowName": "invoice.sent",
  "tenant": "tenant_acme",
  "recipients": [{ "externalId": "user_42" }],
  "data": {}
}
```

[テナントごとのブランディング](/docs/platform/features/tenants)を参照してください。
