title: オブジェクト & 購読 API
description: ビジネスエンティティ（オブジェクト）の登録およびサブスクライバーの監視登録を管理するための、サーバー側エンドポイント。
---

オブジェクトは、アプリケーション内でフィードを生成するビジネス上のエンティティを表します（例: `"projects"`、`"documents"`、`"repositories"` など）。購読（サブスクリプション）を管理することにより、そのエンティティを監視（ウォッチ）しているすべてのサブスクライバーに対してアラートを一斉配信（ファンアウト）できます。

---

## アクセス & パス

これらのエンドポイントは、ダッシュボード JWT セッションとサーバーシークレットキー（`sk_*`）の両方をサポートしています：

- **サーバー間 / SDK 用（`sk_*` 認証）**: ルートパスは `/v1/management/objects`
- **ダッシュボード画面用（JWT 認証）**: ルートパスは `/v1/objects`

---

## エンドポイント概要

| メソッド | 管理用パス (`sk_*`)                                | ダッシュボード用パス (JWT)              | 説明                                                                   |
| :------- | :------------------------------------------------- | :-------------------------------------- | :--------------------------------------------------------------------- |
| `PUT`    | `/v1/management/objects/:collection/:externalId`   | `/v1/objects/:collection/:externalId`   | オブジェクトを作成または更新（Upsert）します。                         |
| `GET`    | `/v1/management/objects/:collection/:externalId`   | `/v1/objects/:collection/:externalId`   | オブジェクトのプロファイルとプロパティを取得します。                   |
| `GET`    | `/v1/management/objects`                           | `/v1/objects`                           | すべてのオブジェクトの一覧を取得します。                               |
| `POST`   | `/v1/management/objects/:col/:extId/subscriptions` | `/v1/objects/:col/:extId/subscriptions` | サブスクライバーをオブジェクトの監視者として追加します（最大100件）。  |
| `DELETE` | `/v1/management/objects/:col/:extId/subscriptions` | `/v1/objects/:col/:extId/subscriptions` | オブジェクトから監視者を削除します。                                   |
| `GET`    | —                                                  | `/v1/objects/:col/:extId/subscriptions` | オブジェクトを監視しているすべてのサブスクライバーの一覧を取得します。 |

## オブジェクトの Upsert

ビジネスエンティティを追加または更新します。

```http
PUT /v1/management/objects/projects/proj_alpha
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json

{
  "name": "Project Alpha",
  "properties": {
    "status": "active",
    "ownerTeam": "engineering"
  }
}
```

- `:collection`: 英小文字、数字、ダッシュ、アンダースコア（`^[a-z][a-z0-9_-]*$`、最大 64 文字）。
- `:externalId`: 一意のエンティティ識別文字列（最大 128 文字）。
- `name`: 人間が判読できる表示ラベル（最大 256 文字）。
- `properties`: 任意のカスタムキー・値のメタデータオブジェクト（最大 50 キー）。

## 購読（サブスクリプション）の管理

オブジェクトを監視するサブスクライバーを管理します。

### 1. 購読の追加

オブジェクトを監視するサブスクライバーを最大 100 件登録します。受信者は現在の環境内にあらかじめ存在している必要があります：

```http
POST /v1/management/objects/projects/proj_alpha/subscriptions
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json

{
  "recipients": ["user_alice", "user_bob"],
  "properties": {
    "role": "editor"
  }
}
```

- `recipients`: サブスクライバーの `externalId` を含む文字列の配列、または `{ "externalId": "..." }` を含むオブジェクトの配列。
- `properties`: 購読固有のオプションのメタデータ。

### 2. 購読の削除

オブジェクトから監視者の登録を解除します：

```http
DELETE /v1/management/objects/projects/proj_alpha/subscriptions
Authorization: Bearer sk_prd_your_secret_key
Content-Type: application/json

{
  "recipients": ["user_bob"]
}
```

- `recipients`: サブスクライバーの `externalId` 文字列の配列。

## ファンアウトトリガー

エンティティを現在監視しているすべてのサブスクライバーに通知するには、ワークフートリガーリクエストで受信者（recipients）としてオブジェクトを指定して渡します。

```json
{
  "workflowName": "project.updated",
  "recipients": [
    {
      "collection": "projects",
      "id": "proj_alpha"
    }
  ]
}
```

## 制限事項

| 制限事項                                 | 値         |
| :--------------------------------------- | :--------- |
| 環境あたりの最大オブジェクト数           | 5,000      |
| オブジェクトあたりの最大監視（購読）者数 | 10,000     |
| 1回の追加/削除バッチ処理の最大数         | 100 受信者 |
| カスタムプロパティキーの最大数           | 50         |
