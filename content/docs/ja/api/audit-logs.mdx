---
title: 監査ログ API
description: 実行ログおよび配信ライフサイクルを表示、検索、追跡するためのダッシュボードエンドポイント。
---

監査ログ（Audit Logs）は、トリガーされたワークフローと配信ステップの履歴を記録し、すべてのメッセージの正確なステータスとペイロードの詳細を追跡できるようにします。

---

## 認証 & アクセス

- **ベースパス**: `/v1/audit-logs`
- **認証**: ユーザー JWT セッショントークンが必要です。

---

## エンドポイント概要

| メソッド | パス                                    | 説明                                                                                            |
| :------- | :-------------------------------------- | :---------------------------------------------------------------------------------------------- |
| `GET`    | `/v1/audit-logs?environment=PRODUCTION` | 配信ログの一覧取得とフィルタリング（ページネーション、検索機能付き）。                          |
| `GET`    | `/v1/audit-logs/:id`                    | 完全なステータス、入力/出力、およびトレーサーのライフサイクルステップのメトリクスを取得します。 |

---

## 監査ログの一覧取得

環境、フィルター、または検索用語に一致するログを時系列で取得します。

```http
GET /v1/audit-logs?environment=PRODUCTION&page=1&limit=20&search=alex
Authorization: Bearer <jwt_dashboard_token>
```

### クエリフィルター

- `environment`: `DEVELOPMENT`、`STAGING`、または `PRODUCTION`（デフォルトは `DEVELOPMENT`）。
- `search`: サブスクライバーのメールアドレス、外部 ID、ログ ID、またはワークフロー名でフィルタリングします（最低3文字）。
- `status`: 実行ステータスでフィルタリングします（例: `DELIVERED`、`FAILED`、`BOUNCED`）。
- `channel`: 配信チャネルでフィルタリングします（例: `EMAIL`、`SMS`、`PUSH`、`WEBHOOK`）。
- `timeRange`: プリセット値を使用してフィルタリングします: `1h`、`6h`、`24h`、`7d`、`30d`。
- `dateFrom` / `dateTo`: カスタムの日付範囲フィルター（ISO 文字列）。
- `sortBy`: ソート対象フィールド: `executedAt`、`status`、`channel`、`retryCount`、`workflowName`、`subscriber`。
- `sortDir`: ソート順: `asc` または `desc`（デフォルトは `desc`）。

**レスポンスボディ:**

```json
{
  "logs": [
    {
      "id": "2db4c803-10ac-4bfa-8bf2-0cfb4db1b392",
      "executedAt": "2026-07-28T21:00:00.000Z",
      "channel": "EMAIL",
      "status": "DELIVERED",
      "retryCount": 0,
      "workflowName": "billing.invoice",
      "subscriber": {
        "externalId": "user_42",
        "email": "alex@example.com"
      }
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 20,
  "environment": "PRODUCTION",
  "sortBy": "executedAt",
  "sortDir": "desc"
}
```

## 配信ログ詳細の取得

ペイロード変数やトレーサーのライフサイクルを含む、完全なデバッグ情報を取得します。

```http
GET /v1/audit-logs/2db4c803-10ac-4bfa-8bf2-0cfb4db1b392
Authorization: Bearer <jwt_dashboard_token>
```
